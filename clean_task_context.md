## BrilliantLessonRunner.jsx findings
**Props:** `lesson, steps, week, phase, onExit, onComplete, onNextLesson, onSwitchToReader, lessonIndex, totalLessons`.

**Step fields it reads:** `title`, `description` (shown in an optional "Concept Briefing" card), `prompt`, `type`, `props`,
`explanation`, `isTeachingStep`. `formatText()` splits text into paragraphs on `\n\n` and renders `` `code` `` spans.

**State:** `currentStepIdx`, `isValid`, `hasAnswer`, `isSubmitted`, `showCelebration`. Everything resets when the step or lesson changes.

**Teaching vs challenge (`isTeaching`):** a step counts as teaching if `isTeachingStep`, or its type is one of EXPLORE / PIPELINE_FLOW /
TYPE_CASTING / SHORT_CIRCUIT / BRANCHING / TRUTHINESS_SCALE / ITERATOR_PROTOCOL / LOOP_CONTROL, or it is STRING_SLICER without
`targetSlice`, or MEMORY_MODEL without `target`. Teaching steps show only "Continue". Challenge steps go Check Answer → (Continue | Try Again).

**Widget selection:** `renderWidget()` is a hard-coded `switch(step.type)` over all 17 widgets, with InteractiveExploreWidget as the
fallback. Scrubber, Slider, Explore and Pipeline are not passed `isSubmitted`.

**Check gating:** `canCheck = hasAnswer || type === SCRUBBER || type === SLIDER`.

**Feedback:** one `step.explanation` string in an `.explanation-drawer`, coloured by `isValid`. The bottom dock shows generic messages.
**Missing:** no per-choice / misconception feedback, no hint drawer, no idea of screen roles
(hook / mental_model / manipulation / bug_hunt / boss_synthesis).

**Header/UI:** step progress bars, "Step X of N", a badge built from `week.title.split(':')[0]`, "Lesson i/total", an optional
"Full Article" button (`onSwitchToReader`), and a celebration modal (+25 XP, Next Lesson / Back / Review).

## Widget contract details that matter for authoring `m1-1`
- **Prediction:** `props.options[] = { id?, text, isCorrect }`. Selecting reports `(isCorrect, true)`. Per-choice `feedback` text is **not rendered yet**.
- **CodeFill:** one `{slot1}` in `template`; `chips[]`; `correctAnswer` (exact string match).
- **CodeChallenge:** `language, starterCode, expectedOutput` (passes if trimmed output *contains* it), `hints[]` (shows only `hints[0]`).
- **Scrubber:** built for arrays: `initialArray`, `frames[{ low/mid/high | left/right, eliminated[], desc }]`. Becomes valid once the last frame is reached.
- **PyObjectMemory:** fixed presets `bind_both | reassign_x | mutate_list`. In challenge mode, `props.target` = the required preset.
- **TypeCasting:** fixed list of candidate values; no props used; always valid.
- **StringSlicer:** `word, targetSlice?, initialStart?, initialStop?`. Step `-1` returns the whole string reversed and ignores start/stop.
- **SortOrder:** `items[{ id, text }]`, `correctOrder[ids]`. **Slider:** shows Big-O bars only. **Explore:** `insights[]` or `concept/trap/takeaway`.
