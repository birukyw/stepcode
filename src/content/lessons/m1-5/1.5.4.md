# Flexible Interfaces & Mutable Default Traps

A function's signature is its user interface. Good interfaces make the common case short and the unusual case possible. Python gives you several tools for that: default values, keyword arguments, and parameters that accept any number of values. It also has one famous trap hidden in default values, which this lesson takes apart.

## Default values

Give a parameter a default and callers may leave it out.

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Ada"))
print(greet("Ada", "Welcome back"))
```

```text
Hello, Ada!
Welcome back, Ada!
```

Parameters with defaults must come **after** those without. `def greet(greeting="Hello", name)` is a syntax error, because Python could not tell which argument is which.

## Keyword arguments

Any argument can be passed by name. That makes calls self-explanatory, and lets you skip over defaults you do not want to change.

```python
def make_box(width, height, border="*", fill=" "):
    rows = []
    for r in range(height):
        if r == 0 or r == height - 1:
            rows.append(border * width)
        else:
            rows.append(border + fill * (width - 2) + border)
    return "\n".join(rows)

print(make_box(6, 3))
print(make_box(6, 3, fill="."))
```

```text
******
*    *
******
******
*....*
******
```

Compare `make_box(6, 3, fill=".")` with `make_box(6, 3, "*", ".")`. The keyword version says exactly what is being changed. Booleans in particular should almost always be passed by keyword: `save(report, overwrite=True)` reads far better than `save(report, True)`.

## Keyword-only parameters

A bare `*` in the signature means "everything after this must be passed by name". Use it to force clarity at the call site.

```python
def connect(host, *, timeout=5, retries=3):
    return f"{host} timeout={timeout} retries={retries}"

print(connect("db.local", retries=5))
```

```text
db.local timeout=5 retries=5
```

Calling `connect("db.local", 10)` now raises a `TypeError`, which stops a reader from guessing what `10` means.

## Any number of arguments: *args

A parameter written `*args` collects any extra positional arguments into a **tuple**.

```python
def total(*numbers):
    result = 0
    for n in numbers:
        result += n
    return result

print(total(1, 2, 3))
print(total(5))
print(total())
```

```text
6
5
0
```

The name after the star is up to you. `args` is the convention when there is no better one. The reverse also works: a star at the **call** unpacks a list into separate arguments.

```python
def total(*numbers):
    return sum(numbers)

values = [4, 5, 6]
print(total(*values))
```

```text
15
```

## Any number of keyword arguments: **kwargs

Two stars collect extra keyword arguments into a **dictionary**. Dictionaries arrive properly in module 1.6, so treat this as a preview.

```python
def describe(name, **details):
    parts = [name]
    for key, value in details.items():
        parts.append(f"{key}={value}")
    return ", ".join(parts)

print(describe("Ada", born=1815, field="mathematics"))
```

```text
Ada, born=1815, field=mathematics
```

## Parameter order

When you combine them, the order in a signature is fixed:

```text
def f(positional, with_default=1, *args, keyword_only, **kwargs):
```

You will rarely need all of them at once. Most good functions use two or three plain parameters, sometimes with a default.

## The mutable default trap

Here is a function that looks perfectly reasonable:

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("apple"))
print(add_item("banana"))
```

```text
['apple']
['apple', 'banana']
```

The second call was meant to start a fresh list, but `"apple"` is still there. Why?

A default value is created **once**, when the `def` line runs, not each time the function is called. Every call that omits `items` receives **the same list object**. The first call appended to it, and the second call saw that same, now-modified list. It is the aliasing problem from lesson 1.4.4, hiding in a signature.

The fix is to use `None` as the default and create a new list inside the function:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("apple"))
print(add_item("banana"))
```

```text
['apple']
['banana']
```

Now each call that omits `items` builds its own fresh list.

> **Remember:** Never use a mutable value such as a list, dictionary or set as a default. Use `None` and create the object inside the function. Immutable defaults such as numbers, strings, `None` and tuples are always safe.

## Designing a good interface

- **Required things are positional.** The data the function works on comes first.
- **Options have defaults.** Choose defaults that suit the common case.
- **Unclear options are keyword-only.** Especially booleans.
- **Keep parameter lists short.** More than four or five parameters usually means the function does too much.

## Common mistakes

- **Mutable default values.** Use `None` instead.
- **A default parameter before a required one.** That is a syntax error.
- **Passing a boolean positionally.** `f(data, True, False)` is unreadable.
- **Overusing `*args`.** A plain list parameter is often clearer.
- **Passing the same argument twice**, by position and by keyword, which raises a `TypeError`.

```python
def power(base, exponent=2):
    return base ** exponent

print(power(5))      # 25
print(power(2, 10))  # 1024
```

```python
def average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(average(2, 4, 9))   # 5.0
```

```python
def register(name, roster=None):
    if roster is None:
        roster = []
    roster.append(name)
    return roster

print(register("Ada"))     # ['Ada']
print(register("Linus"))   # ['Linus']
```

```python
def format_price(amount, *, currency="$", decimals=2):
    return f"{currency}{amount:.{decimals}f}"

print(format_price(3.5))
print(format_price(3.5, currency="EUR "))
```

## Recap

- Defaults make parameters optional and must come after required ones.
- Keyword arguments make calls readable. A bare `*` forces keyword-only parameters.
- `*args` collects extra positional arguments into a tuple, and `**kwargs` collects keyword arguments into a dictionary.
- Defaults are evaluated once. Never use a list, dictionary or set as a default. Use `None`.
