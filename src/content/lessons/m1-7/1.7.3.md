# Reading & Writing Files

So far, everything your programs knew vanished when they stopped. Variables live in memory, and memory is wiped. **Files** are how a program remembers: a to-do list that survives a restart, a score table, a log, a configuration. This lesson shows you how to write text to a file, read it back, and do it safely.

> **Tip:** In this course the editor runs your Python in the browser, where files live in a small private scratch area that is reset when the page reloads. The code is exactly the same as on a real computer. The only difference is where the files end up.

## Writing a file

`open(name, "w")` opens a file for **writing** (creating it, or **erasing** an existing one). Always use `with`, which closes the file for you when the block ends, even if something fails:

```python
with open("notes.txt", "w") as f:
    f.write("Buy milk\n")
    f.write("Learn Python\n")

print("saved")
```

```text
saved
```

Two details:

- `write` writes **exactly** what you give it. It does not add a newline, so you add `"\n"` yourself.
- The `with` block is why you never need to remember `f.close()`.

## Reading it back

```python
with open("notes.txt", "w") as f:
    f.write("Buy milk\nLearn Python\nWalk the dog\n")

with open("notes.txt") as f:
    content = f.read()

print(repr(content))
print(content.count("\n"), "lines")
```

```text
'Buy milk\nLearn Python\nWalk the dog\n'
3 lines
```

`open(name)` with no mode means `"r"`, read. `f.read()` returns the whole file as one string, including the `\n` characters.

## Reading line by line

For anything bigger than a few lines, loop over the file. Each item is one line, newline included, so `strip()` it:

```python
with open("tasks.txt", "w") as f:
    f.write("write code\ntest code\nship code\n")

with open("tasks.txt") as f:
    for number, line in enumerate(f, start=1):
        print(number, line.strip())
```

```text
1 write code
2 test code
3 ship code
```

Looping like this reads **one line at a time**, so it works on a file of a million lines without loading it all into memory. When you do want all the lines in a list:

```python
with open("tasks.txt", "w") as f:
    f.write("write code\ntest code\nship code\n")

with open("tasks.txt") as f:
    lines = f.read().splitlines()

print(lines)
```

```text
['write code', 'test code', 'ship code']
```

`splitlines()` splits on line breaks and drops them.

## Modes: w, a, r

| Mode | Meaning | If the file exists | If it does not |
|---|---|---|---|
| `"r"` | read (default) | read it | **error** |
| `"w"` | write | **erased**, then written | created |
| `"a"` | append | new text goes on the end | created |

Appending keeps old content, so a log grows over time:

```python
with open("log.txt", "w") as f:
    f.write("start\n")

for event in ["login", "click", "logout"]:
    with open("log.txt", "a") as f:
        f.write(event + "\n")

with open("log.txt") as f:
    print(f.read().splitlines())
```

```text
['start', 'login', 'click', 'logout']
```

The most painful mistake is opening an important file with `"w"` by accident. It is wiped instantly.

## When the file is missing

Reading a file that does not exist is an error you now know how to handle (lesson 1.7.2):

```python
def read_lines(path):
    try:
        with open(path) as f:
            return f.read().splitlines()
    except FileNotFoundError:
        return []

print(read_lines("does_not_exist.txt"))
```

```text
[]
```

## A real example: a persistent score table

Store records as lines `name,score`, and load them back into a dictionary:

```python
def save_scores(path, scores):
    with open(path, "w") as f:
        for name in sorted(scores):
            f.write(name + "," + str(scores[name]) + "\n")

def load_scores(path):
    scores = {}
    try:
        with open(path) as f:
            for line in f:
                name, _, value = line.strip().partition(",")
                if name and value.isdigit():
                    scores[name] = int(value)
    except FileNotFoundError:
        pass
    return scores

save_scores("scores.csv", {"ada": 90, "linus": 75, "grace": 99})
print(load_scores("scores.csv"))
print(load_scores("nothing_here.csv"))
```

```text
{'ada': 90, 'grace': 99, 'linus': 75}
{}
```

The loader is **defensive**: it skips blank or malformed lines instead of crashing, and a missing file gives an empty table. That is the mindset for any data that comes from outside your program, because outside data is always a little broken.

## CSV and JSON

Handling your own `name,score` format works until a name contains a comma. For real-world data, use the standard tools, which you will meet in the next lesson:

```python
import csv, json

rows = [["name", "city"], ["Ada", "London, UK"], ["Linus", "Helsinki"]]
with open("people.csv", "w", newline="") as f:
    csv.writer(f).writerows(rows)

with open("people.csv", newline="") as f:
    print(list(csv.reader(f)))

data = {"scores": [1, 2, 3], "name": "Ada"}
with open("data.json", "w") as f:
    json.dump(data, f)

with open("data.json") as f:
    print(json.load(f) == data)
```

```text
[['name', 'city'], ['Ada', 'London, UK'], ['Linus', 'Helsinki']]
True
```

The `csv` module handled the comma inside "London, UK" correctly, which a naive `split(",")` would have broken. JSON saves nested lists and dictionaries, the same shapes you built in module 1.6.

## Encoding: text is bytes underneath

Files hold bytes, and an **encoding** says how characters become bytes. The sensible default today is UTF-8. When you work with names, accents or emoji, say so explicitly:

```python
with open("greeting.txt", "w", encoding="utf-8") as f:
    f.write("Héllo, 世界\n")

with open("greeting.txt", encoding="utf-8") as f:
    print(f.read().strip())
```

```text
Héllo, 世界
```

## Paths

A file name like `"notes.txt"` is relative to the folder the program runs in. The `pathlib` module treats paths as objects and is nicer than gluing strings together:

```python
from pathlib import Path

folder = Path("reports")
folder.mkdir(exist_ok=True)
target = folder / "summary.txt"
target.write_text("all good\n")

print(target.read_text().strip())
print(target.exists(), target.suffix, target.name)
```

```text
all good
True .txt summary.txt
```

`Path.read_text()` and `write_text()` are shortcuts for small files. The `/` operator joins path pieces correctly on every operating system.

## Common mistakes

- **Forgetting `"\n"`** when writing lines: everything lands on one line.
- **Opening with `"w"` and wiping a file** you wanted to extend. Use `"a"`.
- **Not using `with`,** which risks files left open or half-written.
- **Forgetting that `read()` returns a string,** so numbers need `int(...)` or `float(...)`.
- **Trusting file contents.** Expect blank lines, missing fields and bad values.

## Practice

1. Write `count_lines(path)` returning how many lines a file has (0 if it is missing).
2. Write `append_todo(path, text)` that adds a line, then `read_todos(path)` returning the list.
3. Write `word_count_file(path)` returning how many words are in the file.
4. Write `copy_upper(src, dst)` that copies a file, converting each line to uppercase.

+++ Solutions
```python
def count_lines(path):
    try:
        with open(path) as f:
            return sum(1 for _ in f)
    except FileNotFoundError:
        return 0

def append_todo(path, text):
    with open(path, "a") as f:
        f.write(text + "\n")

def read_todos(path):
    try:
        with open(path) as f:
            return f.read().splitlines()
    except FileNotFoundError:
        return []

def word_count_file(path):
    with open(path) as f:
        return len(f.read().split())

def copy_upper(src, dst):
    with open(src) as a, open(dst, "w") as b:
        for line in a:
            b.write(line.upper())

append_todo("todo_demo.txt", "first")
append_todo("todo_demo.txt", "second")
print(read_todos("todo_demo.txt"), count_lines("todo_demo.txt"), count_lines("missing.txt"))
copy_upper("todo_demo.txt", "todo_up.txt")
print(read_todos("todo_up.txt"), word_count_file("todo_up.txt"))   # ['FIRST', 'SECOND'] 2
```

## Recap

- `open(path, mode)` opens a file: `"r"` read (default), `"w"` write (erases), `"a"` append. Always use `with` so the file is closed for you.
- `write` adds no newline. `read()` gives one string, a loop gives one line at a time, and `splitlines()` gives a list.
- Handle `FileNotFoundError`, and treat file contents as untrusted: skip bad lines.
- `csv` and `json` handle structured data safely, and `pathlib.Path` makes paths easy.
- Say `encoding="utf-8"` for text with accents or symbols.
