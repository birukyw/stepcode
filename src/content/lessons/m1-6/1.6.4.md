# Sets: Uniqueness & Venn Algebra

A **set** is a collection of unique values with no order. It is built on the same hashing trick as a dictionary, just without the values, so it answers "is this in here?" instantly. Sets also bring the algebra of Venn diagrams to your code: union, intersection and difference in a single operator.

## Making a set

Write a set with curly braces, or convert another collection with `set()`. Duplicates disappear.

```python
colors = {"red", "green", "red", "blue", "green"}
print(len(colors))
print(sorted(colors))

letters = set("mississippi")
print(sorted(letters))
```

```text
3
['blue', 'green', 'red']
['i', 'm', 'p', 's']
```

Sets have **no order**, so Python may print their items in any order, and that order can change between runs. That is why every example in this lesson wraps sets in `sorted()` before printing.

> **Watch out:** `{}` is an empty **dictionary**, not an empty set. Write an empty set as `set()`.

```python
print(type({}))
print(type(set()))
```

```text
<class 'dict'>
<class 'set'>
```

## Removing duplicates

The most common use of a set is deduplication:

```python
visits = ["home", "about", "home", "blog", "about", "home"]
unique_pages = set(visits)
print(len(visits), "visits to", len(unique_pages), "pages")
print(sorted(unique_pages))
```

```text
6 visits to 3 pages
['about', 'blog', 'home']
```

If you need to keep the **original order** while removing duplicates, use a set to remember what you have seen and build a list:

```python
visits = ["home", "about", "home", "blog", "about", "home"]
seen = set()
ordered = []

for page in visits:
    if page not in seen:
        seen.add(page)
        ordered.append(page)

print(ordered)
```

```text
['home', 'about', 'blog']
```

## Fast membership

`x in some_set` is O(1), just like a dictionary key lookup, while `x in some_list` is O(n). When you test membership many times, convert to a set first.

```python
banned = {"spam", "scam", "phish"}

for word in "this is not a scam honestly".split():
    if word in banned:
        print("blocked:", word)
```

```text
blocked: scam
```

## Adding and removing

```python
tags = {"python", "beginner"}

tags.add("loops")
tags.add("python")
tags.discard("beginner")
tags.discard("missing")

print(sorted(tags))
```

```text
['loops', 'python']
```

Adding an existing item does nothing. `discard` removes an item if present and is silent otherwise. `remove` does the same but raises a `KeyError` when the item is missing.

Like dictionary keys, set items must be hashable, so a set can hold numbers, strings and tuples but not lists.

## Venn algebra

Two student cohorts, one in the morning and one in the evening:

```python
morning = {"Ada", "Linus", "Grace", "Guido"}
evening = {"Grace", "Guido", "Margaret", "Tim"}

print(sorted(morning | evening))
print(sorted(morning & evening))
print(sorted(morning - evening))
print(sorted(morning ^ evening))
```

```text
['Ada', 'Grace', 'Guido', 'Linus', 'Margaret', 'Tim']
['Grace', 'Guido']
['Ada', 'Linus']
['Ada', 'Linus', 'Margaret', 'Tim']
```

| Operator | Name | Meaning |
|---|---|---|
| `a \| b` | union | in either |
| `a & b` | intersection | in both |
| `a - b` | difference | in `a` but not `b` |
| `a ^ b` | symmetric difference | in exactly one |

Each line of the example answers a real question in one expression: who attends at all, who attends both, who only comes in the morning, and who attends exactly one session. Writing those with loops would take a dozen lines each.

## Subsets

`<=` asks whether every item of one set is in another.

```python
required = {"python", "git"}
alice = {"python", "git", "sql"}
bob = {"python"}

print(required <= alice)
print(required <= bob)
print(sorted(required - bob))
```

```text
True
False
['git']
```

The last line shows what Bob is missing. Checking requirements, permissions and prerequisites is a natural fit for sets.

## Sets of words

Combining strings and sets gives quick text analysis:

```python
a = "the quick brown fox jumps over the lazy dog"
b = "the lazy cat sleeps over the warm mat"

words_a = set(a.split())
words_b = set(b.split())

print(len(words_a), len(words_b))
print(sorted(words_a & words_b))
```

```text
8 7
['lazy', 'over', 'the']
```

## Frozen sets

A normal set is mutable, so it cannot be a dictionary key or live inside another set. `frozenset` is an immutable version that can.

```python
pairs = {frozenset({"Ada", "Linus"}), frozenset({"Linus", "Ada"})}
print(len(pairs))
```

```text
1
```

Both pairs contain the same two names, and sets ignore order, so they are equal and only one is kept.

## Common mistakes

- **Writing `{}` for an empty set.** It is a dictionary. Use `set()`.
- **Relying on set order.** There is none. Sort when you display.
- **Indexing a set.** `s[0]` is a `TypeError`, because sets have no positions.
- **Using `remove` on a value that may be missing.** Use `discard`.
- **Putting lists in a set.** Use tuples.

## Recap

- A set holds unique, unordered, hashable items. `set()` is the empty set.
- Sets deduplicate and test membership in O(1).
- `|`, `&`, `-` and `^` give union, intersection, difference and symmetric difference.
- `<=` tests for a subset. `add`, `discard` and `remove` change a set.
- Sort sets before printing, because they have no order.
