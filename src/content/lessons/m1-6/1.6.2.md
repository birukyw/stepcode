# Safe Lookups & Frequency Counting

Asking a dictionary for a key it does not have is an error. Real data is full of missing keys: a word you have not seen yet, a user with no phone number, a product nobody ordered. This lesson covers the tools for looking things up safely, and the counting pattern that is probably the single most common use of dictionaries.

## The KeyError

```python error
stock = {"apples": 12, "pears": 4}
print(stock["plums"])
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(stock["plums"])
KeyError: 'plums'
```

Square-bracket lookup assumes the key exists. When it does not, the program stops.

## Option 1: check first

```python
stock = {"apples": 12, "pears": 4}

if "plums" in stock:
    print(stock["plums"])
else:
    print("no plums")
```

```text
no plums
```

## Option 2: get with a default

`get(key, default)` returns the value if the key exists, and the default if it does not. Without a default it returns `None`.

```python
stock = {"apples": 12, "pears": 4}

print(stock.get("apples", 0))
print(stock.get("plums", 0))
print(stock.get("plums"))
```

```text
12
0
None
```

`get` never raises and never changes the dictionary. It is the right choice when a missing key has a sensible default value.

## Counting with a dictionary

Counting how often each thing appears is called building a **frequency table** or **histogram**. The pattern combines the accumulator from module 1.3 with `get`:

```python
text = "the cat and the hat and the bat"
counts = {}

for word in text.split():
    counts[word] = counts.get(word, 0) + 1

print(counts)
```

```text
{'the': 3, 'cat': 1, 'and': 2, 'hat': 1, 'bat': 1}
```

Read the key line carefully. `counts.get(word, 0)` is the current count, or `0` the first time a word appears. Adding one and storing it back updates the tally. Without `get`, the first appearance of every word would raise a `KeyError`.

Counting letters works the same way:

```python
counts = {}
for ch in "mississippi":
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
```

```text
{'m': 1, 'i': 4, 's': 4, 'p': 2}
```

## Finding the most common item

Once you have counts, `max` with a `key` finds the winner.

```python
counts = {"the": 3, "cat": 1, "and": 2, "hat": 1}

top = max(counts, key=counts.get)
print(top, counts[top])
```

```text
the 3
```

`max(counts)` would compare the **keys** alphabetically. `key=counts.get` tells `max` to compare the values instead.

## setdefault for grouping

`setdefault(key, default)` returns the value for `key`. If the key is missing, it first stores the default and then returns it. This makes grouping items into lists concise:

```python
words = ["apple", "avocado", "banana", "blueberry", "cherry"]
groups = {}

for word in words:
    groups.setdefault(word[0], []).append(word)

print(groups)
```

```text
{'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
```

For each word, `setdefault` guarantees a list exists under its first letter, and `append` adds the word to it. The list is created only for the first word of each group.

## Counter

Counting is so common that Python includes a ready-made tool for it in the `collections` module.

```python
from collections import Counter

letters = Counter("banana")
print(letters)
print(letters["a"])
print(letters["z"])
print(letters.most_common(2))
```

```text
Counter({'a': 3, 'n': 2, 'b': 1})
3
0
[('a', 3), ('n', 2)]
```

A `Counter` is a dictionary that returns `0` for missing keys instead of raising, and adds `most_common(n)`. Write the manual version first so you understand it, then reach for `Counter` in real code.

## Choosing a lookup style

| Situation | Use |
|---|---|
| The key must exist, and a missing key is a bug | `d[key]` |
| A missing key has a sensible default | `d.get(key, default)` |
| You need to branch on presence | `if key in d:` |
| Building lists or counts under keys | `setdefault`, `get(..., 0) + 1`, or `Counter` |

Using `d[key]` is not bad practice. When a key should always be there, a loud `KeyError` is better than silently carrying on with a wrong default.

## Common mistakes

- **`counts[word] += 1` on an empty dictionary.** The first appearance raises `KeyError`. Use `get(word, 0) + 1`.
- **`max(d)` to find the most frequent item.** It compares keys. Use `max(d, key=d.get)`.
- **Using `get` everywhere.** It hides bugs when a key really should exist.
- **Forgetting that `get` returns `None` with no default.** `None + 1` is a `TypeError`.

## Practice

1. Count how many times each character appears in `"hello world"`, skipping spaces.
2. Given `prices = {"tea": 2.5, "cake": 4.0}`, print the price of `"coffee"`, falling back to `0.0`.
3. Group these names by length: `["Ada", "Linus", "Grace", "Guido", "Tim"]`.
4. Find the most common word in `"to be or not to be that is the question to ask"`.

+++ Solutions
```python
counts = {}
for ch in "hello world":
    if ch != " ":
        counts[ch] = counts.get(ch, 0) + 1
print(counts)
```

```python
prices = {"tea": 2.5, "cake": 4.0}
print(prices.get("coffee", 0.0))
```

```python
groups = {}
for name in ["Ada", "Linus", "Grace", "Guido", "Tim"]:
    groups.setdefault(len(name), []).append(name)
print(groups)   # {3: ['Ada', 'Tim'], 5: ['Linus', 'Grace', 'Guido']}
```

```python
counts = {}
for word in "to be or not to be that is the question to ask".split():
    counts[word] = counts.get(word, 0) + 1
best = max(counts, key=counts.get)
print(best, counts[best])   # to 3
```

## Recap

- `d[key]` raises `KeyError` when the key is missing. Use it when the key must exist.
- `d.get(key, default)` returns a default instead. `key in d` lets you branch.
- The counting pattern is `counts[x] = counts.get(x, 0) + 1`.
- `setdefault(key, [])` groups items into lists. `max(d, key=d.get)` finds the top count.
- `collections.Counter` packages counting and `most_common`.
