# Iterating & Transforming Dictionaries

You can look values up in a dictionary. Now you will walk through all of it: every key, every value, every pair. This lesson covers the three views a dictionary offers, how to sort and reshape dictionaries, and how to combine two of them.

## Three ways to loop

A dictionary gives you three **views**: its keys, its values, and its key-value pairs.

```python
scores = {"Ada": 91, "Linus": 84, "Grace": 97}

for name in scores:
    print(name)

for value in scores.values():
    print(value)

for name, value in scores.items():
    print(f"{name} scored {value}")
```

```text
Ada
Linus
Grace
91
84
97
Ada scored 91
Linus scored 84
Grace scored 97
```

- Looping over the dictionary itself, or over `scores.keys()`, gives the keys.
- `scores.values()` gives just the values.
- `scores.items()` gives `(key, value)` tuples, which you unpack right in the `for` line.

`items()` is the one you will use most, because you usually want both halves. Iteration follows insertion order.

## Aggregating values

The views work with the built-in functions you already know.

```python
scores = {"Ada": 91, "Linus": 84, "Grace": 97}

print(sum(scores.values()))
print(max(scores.values()))
print(sum(scores.values()) / len(scores))
print(sorted(scores))
```

```text
272
97
90.66666666666667
['Ada', 'Grace', 'Linus']
```

`sorted(scores)` sorts the keys and returns a list.

## Sorting by value

To rank by value, sort the items with a `key` that picks the second element of each pair.

```python
scores = {"Ada": 91, "Linus": 84, "Grace": 97}

ranking = sorted(scores.items(), key=lambda pair: pair[1], reverse=True)
print(ranking)

for place, (name, score) in enumerate(ranking, 1):
    print(f"{place}. {name} ({score})")
```

```text
[('Grace', 97), ('Ada', 91), ('Linus', 84)]
1. Grace (97)
2. Ada (91)
3. Linus (84)
```

The result is a list of tuples, which is the right shape for a ranking because a ranking is ordered. The `(name, score)` in the second `for` line unpacks a tuple that is itself inside the tuple from `enumerate`.

## Building a new dictionary

Transforming a dictionary usually means building a new one in a loop. Here every price gets a 10% increase:

```python
prices = {"tea": 2.0, "cake": 4.0, "soup": 6.5}
raised = {}

for item, price in prices.items():
    raised[item] = round(price * 1.1, 2)

print(raised)
```

```text
{'tea': 2.2, 'cake': 4.4, 'soup': 7.15}
```

Filtering works the same way, with an `if`:

```python
prices = {"tea": 2.0, "cake": 4.0, "soup": 6.5}
cheap = {}

for item, price in prices.items():
    if price < 5:
        cheap[item] = price

print(cheap)
```

```text
{'tea': 2.0, 'cake': 4.0}
```

## Inverting a dictionary

Swapping keys and values turns a "name to code" map into a "code to name" map.

```python
codes = {"red": "#ff0000", "green": "#00ff00", "blue": "#0000ff"}
by_code = {}

for name, code in codes.items():
    by_code[code] = name

print(by_code["#00ff00"])
```

```text
green
```

> **Watch out:** If two keys share a value, inverting loses data, because the new keys must be unique and the later one overwrites the earlier one. When values can repeat, invert into lists instead with `setdefault(value, []).append(key)`.

## Building from two lists

`zip` pairs up two sequences, and `dict()` turns the pairs into a dictionary.

```python
names = ["Ada", "Linus", "Grace"]
years = [1815, 1969, 1906]

born = dict(zip(names, years))
print(born)
```

```text
{'Ada': 1815, 'Linus': 1969, 'Grace': 1906}
```

## Merging dictionaries

The `|` operator merges two dictionaries into a new one. When both have a key, the right-hand side wins.

```python
defaults = {"theme": "dark", "font": 14, "autosave": True}
user = {"font": 16}

settings = defaults | user
print(settings)
```

```text
{'theme': 'dark', 'font': 16, 'autosave': True}
```

This "defaults overlaid with user choices" pattern is everywhere in real software. `defaults.update(user)` does the same thing **in place**, changing `defaults` itself.

## Removing items

```python
stock = {"apples": 12, "pears": 4, "plums": 9}

removed = stock.pop("pears")
print(removed, stock)

print(stock.pop("kiwi", 0))
```

```text
4 {'apples': 12, 'plums': 9}
0
```

`pop(key)` removes a key and returns its value. With a second argument it returns that default instead of raising when the key is missing.

## Do not change size while looping

Adding or removing keys while looping over the same dictionary is an error:

```python error
stock = {"apples": 0, "pears": 4, "plums": 0}

for item in stock:
    if stock[item] == 0:
        del stock[item]
```

```text
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    for item in stock:
RuntimeError: dictionary changed size during iteration
```

Loop over a **copy of the keys** instead, or build a new dictionary of the items you want to keep:

```python
stock = {"apples": 0, "pears": 4, "plums": 0}

for item in list(stock):
    if stock[item] == 0:
        del stock[item]

print(stock)
```

```text
{'pears': 4}
```

Changing the **values** of existing keys during a loop is fine. Only adding or removing keys is a problem.

## Common mistakes

- **Looping over a dictionary and expecting values.** Plain iteration gives keys. Use `.items()`.
- **Sorting a dictionary and expecting a dictionary.** `sorted` returns a list.
- **Inverting a map with duplicate values.** Later keys overwrite earlier ones.
- **Deleting keys while iterating.** Loop over `list(d)` instead.
- **Confusing `|` with `update`.** `|` makes a new dictionary. `update` changes the original.

## Practice

1. Print each item in `{"pen": 1.5, "book": 12.0, "bag": 30.0}` as `pen: $1.50`.
2. Find the total value of the inventory `{"pen": (1.5, 10), "book": (12.0, 2)}`, where each value is `(price, quantity)`.
3. Merge `{"a": 1, "b": 2}` with `{"b": 3, "c": 4}` and print the result.
4. Remove every item with a price over 10 from the first dictionary, safely.

```python
items = {"pen": 1.5, "book": 12.0, "bag": 30.0}
for name, price in items.items():

```

```python
inventory = {"pen": (1.5, 10), "book": (12.0, 2)}
total = 0
for name, (price, quantity) in inventory.items():
    total += price * quantity
print(total)   # 39.0
```

```python
print({"a": 1, "b": 2} | {"b": 3, "c": 4})   # {'a': 1, 'b': 3, 'c': 4}
```

```python
items = {"pen": 1.5, "book": 12.0, "bag": 30.0}
for name in list(items):
    if items[name] > 10:
        del items[name]
print(items)   # {'pen': 1.5}
```

## Recap

- Loop over keys with `for k in d`, values with `.values()`, and pairs with `.items()`.
- `sorted(d.items(), key=lambda p: p[1])` ranks by value and returns a list of tuples.
- Build transformed or filtered dictionaries in a loop. Invert carefully when values repeat.
- `dict(zip(keys, values))` builds a dictionary from two lists. `a | b` merges, with the right side winning.
- Never add or remove keys while looping over the same dictionary.
