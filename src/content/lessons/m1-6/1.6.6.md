## The documents

```python
    4: "The python language was named after a comedy group.",

print(len(docs), "documents")
```


## Step 1: tokenize

Search engines do not work on raw text. They first break it into normalized **tokens**: lowercase words with punctuation removed.

```python
def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        if ch.isalnum() or ch == " ":
            cleaned += ch
        else:
            cleaned += " "
    return cleaned.split()

print(tokenize("Python is a popular programming language."))
```

```text
['python', 'is', 'a', 'popular', 'programming', 'language']
```

Every character that is not a letter, digit or space becomes a space, so `language.` and `language` turn into the same token.

## Step 2: the slow way

Without an index, every search scans every document:

```python
def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        cleaned += ch if ch.isalnum() or ch == " " else " "
    return cleaned.split()

docs = {
    1: "Python is a popular programming language.",
    2: "Snakes such as the python are not venomous.",
    3: "Learning a programming language takes practice.",
    4: "The python language was named after a comedy group.",
}

def slow_search(docs, word):
    hits = []
    for doc_id, text in docs.items():
        if word in tokenize(text):
            hits.append(doc_id)
    return hits

print(slow_search(docs, "python"))
```

```text
[1, 2, 4]
```

That works for four documents. For a billion, it would re-read every document for every search, which is the O(n) problem from lesson 1.6.1.

## Step 3: the inverted index

The fix is to do the reading **once**, ahead of time. An **inverted index** maps each word to the set of documents that contain it.

```python
def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        cleaned += ch if ch.isalnum() or ch == " " else " "
    return cleaned.split()

docs = {
    1: "Python is a popular programming language.",
    2: "Snakes such as the python are not venomous.",
    3: "Learning a programming language takes practice.",
    4: "The python language was named after a comedy group.",
}

def build_index(docs):
    index = {}
    for doc_id, text in docs.items():
        for word in tokenize(text):
            index.setdefault(word, set()).add(doc_id)
    return index

index = build_index(docs)
print(sorted(index["python"]))
print(sorted(index["language"]))
print(sorted(index["programming"]))
```

```text
[1, 2, 4]
[1, 3, 4]
[1, 3]
```

Now finding the documents for a word is a single dictionary lookup, however many documents there are. It is called "inverted" because a document maps to words, while the index maps words back to documents.

## Step 4: multi-word queries with sets

A query like `python language` usually means "documents containing **all** these words". That is a set intersection. "Documents containing **any** of these words" is a union.

```python
def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        cleaned += ch if ch.isalnum() or ch == " " else " "
    return cleaned.split()

docs = {
    1: "Python is a popular programming language.",
    2: "Snakes such as the python are not venomous.",
    3: "Learning a programming language takes practice.",
    4: "The python language was named after a comedy group.",
}

def build_index(docs):
    index = {}
    for doc_id, text in docs.items():
        for word in tokenize(text):
            index.setdefault(word, set()).add(doc_id)
    return index

def search_all(index, query):
    words = tokenize(query)
    if not words:
        return []
    result = index.get(words[0], set())
    for word in words[1:]:
        result = result & index.get(word, set())
    return sorted(result)

def search_any(index, query):
    result = set()
    for word in tokenize(query):
        result = result | index.get(word, set())
    return sorted(result)

index = build_index(docs)
print(search_all(index, "python language"))
print(search_any(index, "snakes practice"))
print(search_all(index, "python unicorn"))
```

```text
[1, 4]
[2, 3]
[]
```

`index.get(word, set())` treats an unknown word as "no documents", so a query with a word that appears nowhere returns an empty result instead of crashing.

## Step 5: ranking

Returning matches is not enough. A good engine puts the **most relevant** first. A simple, effective score is: how many times do the query words appear in the document?

```python
def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        cleaned += ch if ch.isalnum() or ch == " " else " "
    return cleaned.split()

docs = {
    1: "Python is a popular programming language.",
    2: "Snakes such as the python are not venomous.",
    3: "Learning a programming language takes practice.",
    4: "The python language was named after a comedy group.",
}

def score(text, query_words):
    counts = {}
    for word in tokenize(text):
        counts[word] = counts.get(word, 0) + 1
    total = 0
    for word in query_words:
        total += counts.get(word, 0)
    return total

def rank(docs, query):
    query_words = tokenize(query)
    scored = []
    for doc_id, text in docs.items():
        s = score(text, query_words)
        if s > 0:
            scored.append((s, doc_id))
    scored.sort(key=lambda pair: (-pair[0], pair[1]))
    return scored

for s, doc_id in rank(docs, "python programming language"):
    print(s, doc_id, docs[doc_id])
```

```text
3 1 Python is a popular programming language.
2 3 Learning a programming language takes practice.
2 4 The python language was named after a comedy group.
1 2 Snakes such as the python are not venomous.
```

Document 1 contains all three query words, so it ranks first. The sort key `(-score, doc_id)` puts higher scores first and breaks ties by ID, so the order is always the same.

## What real engines add

You now have the skeleton of real search. Production systems add:

- **Stop words.** Ignoring common words like `the` and `a`, which match everything.
- **Stemming.** Treating `learn`, `learning` and `learned` as one token.
- **Weighting.** Rare words, like `venomous`, count for more than common ones. The classic formula is called TF-IDF.
- **Position data.** Storing where each word appears, so phrase searches work.

Each of these is a small change to the functions you just wrote.

```python
STOP_WORDS = {"the", "a", "is", "as", "are", "not"}

def tokenize(text):
    cleaned = ""
    for ch in text.lower():
        cleaned += ch if ch.isalnum() or ch == " " else " "
    words = []
    for word in cleaned.split():
        if word not in STOP_WORDS:
            words.append(word)
    return words

print(tokenize("The python is not a snake"))   # ['python', 'snake']
print(tokenize("the a is"))                    # []
```

## Recap

- Tokenizing normalizes text into lowercase words without punctuation.
- An inverted index maps each word to the set of documents containing it, built once and queried instantly.
- Set intersection gives "all words" searches, and union gives "any word".
- Ranking sorts matches by a relevance score, with a deterministic tie-breaker.
- Every tool from the earlier modules played a part: strings, loops, functions, lists, dictionaries and sets.
