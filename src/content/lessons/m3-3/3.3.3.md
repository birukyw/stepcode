# Filesystem Engineering & Serialization

In lesson 1.7.3 you read and wrote a text file. Real programs handle **folders full of files**, files that must never be left half-written, data that has to be turned into bytes and back, and structured formats like CSV and JSON. This lesson is the engineering side: navigate the filesystem with `pathlib`, write files **safely**, and **serialize** your data so another program (or your own program next week) can read it.

> **Tip:** In the course editor, your files live in a small private area that resets when the page reloads. All of the code works the same on a real computer. The examples use temporary folders so they never touch anything you care about.

## pathlib: paths as objects

Gluing paths together with strings breaks across operating systems (`/` versus `\`). `pathlib.Path` treats a path as an object with useful methods, and `/` joins pieces correctly everywhere:

```python
from pathlib import Path

p = Path("projects") / "demo" / "notes.txt"
print(p)
print(p.name, p.stem, p.suffix, p.parent)
print(p.with_suffix(".md"), p.with_name("todo.txt"))
print(p.parts)
print(Path("a/b/../c").resolve().name)
```

```text
projects/demo/notes.txt
notes.txt notes .txt projects/demo
projects/demo/notes.md projects/demo/todo.txt
('projects', 'demo', 'notes.txt')
c
```

Building and inspecting a path does not touch the disk. Only the methods that act on the filesystem do:

```python
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    folder = root / "reports" / "2030"
    folder.mkdir(parents=True, exist_ok=True)          # create the whole chain, no error if present

    report = folder / "q1.txt"
    report.write_text("revenue: 100\n")
    (folder / "q2.txt").write_text("revenue: 140\n")
    (folder / "notes.md").write_text("# notes\n")

    print(report.exists(), report.is_file(), folder.is_dir())
    print(report.read_text().strip())
    print(report.stat().st_size, "bytes")
    print(sorted(p.name for p in folder.iterdir()))
    print(sorted(p.name for p in folder.glob("*.txt")))
    print(sorted(str(p.relative_to(root)) for p in root.rglob("*.md")))

    report.rename(folder / "q1-final.txt")
    (folder / "q2.txt").unlink()
    print(sorted(p.name for p in folder.iterdir()))
```

```text
True True True
revenue: 100
13 bytes
['notes.md', 'q1.txt', 'q2.txt']
['q1.txt', 'q2.txt']
['reports/2030/notes.md']
['notes.md', 'q1-final.txt']
```

The tools worth remembering:

| Task | Tool |
|---|---|
| make folders | `mkdir(parents=True, exist_ok=True)` |
| list a folder | `iterdir()` |
| find by pattern | `glob("*.txt")`, and `rglob("*.txt")` to search inside subfolders |
| small file read/write | `read_text()`, `write_text()`, `read_bytes()`, `write_bytes()` |
| info | `exists()`, `is_file()`, `is_dir()`, `stat().st_size` |
| move / delete | `rename()`, `replace()`, `unlink()`, `rmdir()` |

For removing a whole folder tree, use `shutil.rmtree`, and for copying, `shutil.copy` and `shutil.copytree`.

## A practical example: summarising a folder

```python
import tempfile
from pathlib import Path
from collections import Counter

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    for name, content in [("a.py", "x = 1\n" * 3), ("b.py", "y = 2\n"), ("c.txt", "hello\n" * 5), ("sub/d.py", "z = 3\n" * 2)]:
        target = root / name
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(content)

    lines_by_type = Counter()
    for path in root.rglob("*"):
        if path.is_file():
            lines_by_type[path.suffix] += len(path.read_text().splitlines())
    print(dict(lines_by_type))
```

```text
{'.txt': 5, '.py': 6}
```

## Writing safely: never leave a file half-written

Imagine overwriting `settings.json` and the program crashes (or power fails) halfway through the write. The file is now **corrupt**, and the old good copy is gone. The professional fix is an **atomic write**: write the new content to a **temporary file in the same folder**, then swap it into place in one step with `os.replace`, which the operating system performs atomically:

```python
import os
import tempfile
from pathlib import Path

def atomic_write(path, text):
    path = Path(path)
    fd, tmp_name = tempfile.mkstemp(dir=path.parent, prefix=path.name, suffix=".tmp")
    try:
        with os.fdopen(fd, "w") as f:
            f.write(text)
            f.flush()
            os.fsync(f.fileno())               # force the data onto the disk
        os.replace(tmp_name, path)             # atomic swap
    except BaseException:
        if os.path.exists(tmp_name):
            os.remove(tmp_name)
        raise

with tempfile.TemporaryDirectory() as tmp:
    target = Path(tmp) / "settings.txt"
    atomic_write(target, "version=1\n")
    print(target.read_text().strip())

    try:
        atomic_write(target, 12345)             # a bug: write() needs a string
    except TypeError:
        pass
    print(target.read_text().strip())           # still the old, valid content
    print(sorted(p.name for p in Path(tmp).iterdir()))   # no leftover temp files
```

```text
version=1
version=1
['settings.txt']
```

The second call failed in the middle, yet `settings.txt` still holds the good old content and no temporary file is left behind. Readers of the file see either the **complete old version or the complete new one, never a mixture**. The same idea powers editors, package managers and databases.

## Serialization: data to bytes and back

**Serialization** converts a Python object into text or bytes so it can be saved or sent. **Deserialization** reverses it. The choice of format is a design decision:

| Format | Good for | Caution |
|---|---|---|
| **JSON** | data exchange, configs, web APIs | only basic types (no sets, dates, custom classes) |
| **CSV** | tables, spreadsheets | everything comes back as text |
| **pickle** | Python-only snapshots | **unsafe to load from anyone you do not trust** |
| **text/binary files** | custom formats | you design everything |

### JSON

```python
import json

data = {"name": "Ada", "scores": [90, 85.5], "active": True, "boss": None}
text = json.dumps(data, indent=2, sort_keys=True)
print(text)
back = json.loads(text)
print(back == data)

print(json.dumps({"set": [1, 2], "tuple": (1, 2)}))
try:
    json.dumps({"bad": {1, 2}})
except TypeError:
    print("sets are not JSON serializable")
```

```text
{
  "active": true,
  "boss": null,
  "name": "Ada",
  "scores": [
    90,
    85.5
  ]
}
True
{"set": [1, 2], "tuple": [1, 2]}
sets are not JSON serializable
```

JSON has only: strings, numbers, booleans, `null`, lists and objects with string keys. Tuples become lists, and sets and custom objects are rejected.

You can teach `json` about your own types with a `default` function (to encode) and an `object_hook` (to decode):

```python
import json
from dataclasses import dataclass, asdict
from datetime import date

@dataclass
class Event:
    title: str
    when: date

def encode(obj):
    if isinstance(obj, date):
        return {"__date__": obj.isoformat()}
    raise TypeError(f"cannot encode {type(obj).__name__}")

def decode(d):
    if "__date__" in d:
        return date.fromisoformat(d["__date__"])
    return d

event = Event("launch", date(2030, 1, 15))
text = json.dumps(asdict(event), default=encode)
print(text)
restored = Event(**json.loads(text, object_hook=decode))
print(restored == event, restored.when.year)
```

```text
{"title": "launch", "when": {"__date__": "2030-01-15"}}
True 2030
```

### Files and JSON together

`json.dump` and `json.load` (without the `s`) work directly with files. Combine them with the atomic write for safe persistence:

```python
import json
import os
import tempfile
from pathlib import Path

def save_json(path, data):
    path = Path(path)
    fd, tmp = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
    with os.fdopen(fd, "w") as f:
        json.dump(data, f, indent=2)
    os.replace(tmp, path)

def load_json(path, default=None):
    try:
        with open(path) as f:
            return json.load(f)
    except FileNotFoundError:
        return default
    except json.JSONDecodeError:
        return default

with tempfile.TemporaryDirectory() as tmp:
    path = Path(tmp) / "state.json"
    print(load_json(path, {"count": 0}))
    save_json(path, {"count": 7})
    print(load_json(path))
    path.write_text("{ this is not json")
    print(load_json(path, "recovered with default"))
```

```text
{'count': 0}
{'count': 7}
recovered with default
```

A loader that survives a missing or damaged file is the **defensive** style of lesson 1.7.3 made reusable.

### CSV with dictionaries

The `csv` module handles quoting and commas inside fields. `DictReader` and `DictWriter` use the header row as keys:

```python
import csv
import io

rows = [
    {"name": "Ada", "city": "London, UK", "score": 90},
    {"name": "Linus", "city": "Helsinki", "score": 75},
]

buffer = io.StringIO()
writer = csv.DictWriter(buffer, fieldnames=["name", "city", "score"])
writer.writeheader()
writer.writerows(rows)
text = buffer.getvalue()
print(text)

reader = csv.DictReader(io.StringIO(text))
loaded = [{**row, "score": int(row["score"])} for row in reader]
print(loaded == rows)
print(sum(r["score"] for r in loaded) / len(loaded))
```

```text
name,city,score
Ada,"London, UK",90
Linus,Helsinki,75

True
82.5
```

Everything read from a CSV is a **string**, so convert numbers yourself (as the comprehension does). With real files, open them with `newline=""`.

### pickle, and why to be careful

`pickle` can store almost any Python object, but **loading a pickle can run arbitrary code**. Never unpickle data from a source you do not fully trust:

```python
import pickle

snapshot = {"set": {1, 2, 3}, "tuple": (1, 2), "nested": [{"a": 1}]}
blob = pickle.dumps(snapshot)
print(type(blob).__name__, pickle.loads(blob) == snapshot)
```

```text
bytes True
```

Use pickle only for your own private caches. For anything that crosses a trust boundary, use JSON.

## Binary files and encoding

Files hold **bytes**. Text is a layer on top, with an **encoding** (use UTF-8). Open in binary mode (`"rb"`, `"wb"`) when the content is not text:

```python
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    path = Path(tmp) / "blob.bin"
    path.write_bytes(bytes([0, 1, 2, 255]))
    print(list(path.read_bytes()))

    text_path = Path(tmp) / "greeting.txt"
    text_path.write_text("Héllo, 世界", encoding="utf-8")
    raw = text_path.read_bytes()
    print(len("Héllo, 世界"), len(raw))
    print(raw.decode("utf-8"))
```

```text
[0, 1, 2, 255]
9 14
Héllo, 世界
```

The text is 9 characters but 14 bytes, because accented and Chinese characters take several bytes in UTF-8. Always state `encoding="utf-8"` explicitly.

## Walking a directory tree

`os.walk` visits every folder, giving you the folder path, its subfolders and its files. It is the classic way to scan a project:

```python
import os
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    (root / "src").mkdir()
    (root / "src" / "app.py").write_text("print(1)\n")
    (root / "src" / "util.py").write_text("x = 1\n")
    (root / "README.md").write_text("# hi\n")

    found = []
    for folder, subfolders, files in os.walk(root):
        for name in files:
            found.append(os.path.relpath(os.path.join(folder, name), root))
    print(sorted(found))
```

```text
['README.md', 'src/app.py', 'src/util.py']
```

## Common mistakes

- **Building paths with string `+`** instead of `Path` and `/`.
- **Overwriting a file in place,** where a crash leaves it corrupt. Use an atomic write.
- **Opening a file without `with`,** or forgetting `encoding="utf-8"` for text.
- **Treating CSV values as numbers.** They are strings until you convert them.
- **Loading pickles from untrusted sources,** which is a code-execution hole.
- **Expecting JSON to round-trip sets, tuples or dates** unchanged.
- **Writing the temporary file in a different folder,** which makes `os.replace` non-atomic (or fail) across disks. Keep it in the same folder.

## Recap

- `pathlib.Path` represents paths as objects: join with `/`, inspect with `name`, `stem`, `suffix`, `parent`, and act with `mkdir(parents=True, exist_ok=True)`, `iterdir`, `glob`/`rglob`, `read_text`, `write_text`, `rename`, `unlink`. `os.walk` scans a whole tree.
- An **atomic write** (write a temporary file in the same folder, flush and `fsync`, then `os.replace`) means readers see the old complete file or the new complete one, never a half-written one.
- **JSON** is the safe exchange format (basic types only, with `default` and `object_hook` for custom ones). **CSV** needs the `csv` module and manual type conversion. **pickle** is Python-only and **unsafe for untrusted data**.
- Files hold **bytes**. Use UTF-8 explicitly for text, and binary mode (`"rb"`/`"wb"`) for everything else.
- A loader should survive a missing or damaged file by returning a default.
