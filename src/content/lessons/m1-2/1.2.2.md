# Forking the Path

Until now every program has run straight through, every line, in order. Real programs need to choose. An `if` statement runs a block of code only when a condition is true, which turns a straight line into a fork in the road.

## The if statement

```python
temperature = 31

if temperature > 30:
    print("It is hot outside")
    print("Drink some water")

print("Done checking")
```

```text
It is hot outside
Drink some water
Done checking
```

There are three parts to notice:

1. The keyword `if`, followed by a condition, which is any expression that gives a boolean.
2. A colon `:` at the end of the line.
3. An **indented block** of code underneath. Only those indented lines belong to the `if`.

The last `print` is not indented, so it runs whatever the temperature is. Change `temperature` to `20` and run it again to see the block skipped.

## Indentation is syntax

Many languages use braces to mark a block. Python uses indentation, so the spacing is not decoration: it is part of the program. The convention is four spaces per level, and every line in a block must use the same amount.

Forgetting to indent the block is an error Python reports clearly:

```python error
if True:
print("x")
```

```text
  File "main.py", line 2
    print("x")
    ^
IndentationError: expected an indented block after 'if' statement on line 1
```

Mixing tabs with spaces causes confusing errors, so configure your editor to insert four spaces when you press Tab. This editor already does.

## else

`else` handles the case where the condition was false. Exactly one of the two blocks runs, never both and never neither.

```python
age = 16

if age >= 18:
    print("You can vote")
else:
    print("Too young to vote")
```

```text
Too young to vote
```

`else` has no condition of its own. It simply means "otherwise".

## Conditions are just expressions

Anything that evaluates to a boolean works as a condition, including variables that already hold one.

```python
is_member = True
total = 120

if is_member:
    total = total * 0.9

print(total)
```

```text
108.0
```

Here the block changes a variable. This pattern of starting with a default and adjusting it under some condition is extremely common.

## Making a choice from input

Combining `input()` with `if` is how programs react to users. Remember that `input()` returns a string, so convert numbers first.

```python
password = input("Password: ")

if password == "open sesame":
    print("Access granted")
else:
    print("Access denied")
```

Try it in the editor. Open the **Input** box under the terminal and type a password before you press Run.

## Nested decisions

A block can contain another `if`. Each extra level of indentation is a new fork.

```python
weight = 12
is_fragile = True

if weight > 10:
    if is_fragile:
        print("Heavy and fragile: use the careful lane")
    else:
        print("Heavy: use the main lane")
else:
    print("Light: use the express lane")
```

```text
Heavy and fragile: use the careful lane
```

Nesting works but gets hard to read quickly. When you have more than two levels, look for ways to combine conditions, which lesson 1.2.4 covers, or to split into a chain, which lesson 1.2.3 covers.

## The conditional expression

For a simple either-or **value**, Python has a one-line form: `value_if_true if condition else value_if_false`.

```python
weight = 25
lane = "freight" if weight > 20 else "standard"
print(lane)
```

```text
freight
```

It is an expression, so you can use it anywhere a value is allowed, such as inside an f-string. Keep it for simple cases. If it needs a second glance to read, use a regular `if` statement.

## Placeholder blocks with pass

A block cannot be empty. When you want to sketch structure now and fill in later, use `pass`, a statement that does nothing.

```python
if False:
    pass   # TODO: handle this case
print("still runs")
```

## Common mistakes

- **Missing colon** after the condition gives a `SyntaxError`.
- **Wrong indentation.** The code you expected inside the `if` ends up outside it, or Python raises an `IndentationError`.
- **`=` instead of `==`.** `if x = 5:` is a syntax error. Python's message even suggests `==`.
- **Writing `if x == True:`.** Write `if x:`. It is shorter and handles the same cases.
- **Comparing strings and numbers.** `if age >= 18:` fails if `age` is still a string.

## Recap

- `if condition:` runs an indented block only when the condition is true.
- `else:` runs when it was false. Exactly one block runs.
- Indentation defines blocks. Use four spaces, consistently.
- Conditions are boolean expressions, including variables that hold booleans.
- `a if cond else b` is the one-line form for choosing between two values.
