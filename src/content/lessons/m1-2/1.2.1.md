# Truth, Lies & Comparisons

Programs make decisions, and every decision starts with a question that has a yes-or-no answer. Python represents those answers with a type called `bool`, which has exactly two values: `True` and `False`. This lesson covers how to ask the questions. The next lessons cover what to do with the answers.

## Booleans

`True` and `False` are values, just like `7` or `"hello"`. They are capitalised, and they are not strings.

```python
print(True)
print(type(True))
is_ready = False
print(is_ready)
```

```text
True
<class 'bool'>
False
```

You rarely type `True` or `False` by hand. Most of the time they come out of comparisons.

## Comparison operators

A comparison is an expression that evaluates to a boolean.

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `==` | equal to | `5 == 5` | `True` |
| `!=` | not equal to | `5 != 3` | `True` |
| `<` | less than | `3 < 5` | `True` |
| `<=` | less than or equal | `5 <= 5` | `True` |
| `>` | greater than | `3 > 5` | `False` |
| `>=` | greater than or equal | `5 >= 6` | `False` |

```python
age = 17
print(age >= 18)
print(age != 18)
is_adult = age >= 18
print(is_adult)
```

```text
False
True
False
```

The last two lines show something useful: a comparison is an ordinary expression, so you can store its result in a variable and give it a meaningful name.

## One equals sign versus two

This is the most common mistake in this area. A single `=` assigns. A double `==` compares.

```python
x = 5        # assignment: x now points at 5
print(x == 5)  # comparison: is x equal to 5?
```

```text
True
```

Writing `=` where you meant `==` inside a condition is a syntax error, which Python catches for you. Writing `==` where you meant `=` is subtler, because nothing is stored and the line quietly does nothing.

## Chained comparisons

Python lets you chain comparisons the way you would write them in maths. `30 <= x < 75` means "x is at least 30 **and** less than 75".

```python
x = 50
print(30 <= x < 75)
print(30 <= 75 < 60)
```

```text
True
False
```

This reads naturally and works for any number of links. It is also the standard way to express a **half-open interval** such as [30, 75), which includes 30 but not 75. Half-open ranges avoid double counting at the boundaries, which is why Python's `range()` and slicing use them too.

## Comparing different types

Numbers compare across `int` and `float`, so `1 == 1.0` is `True`. But different kinds of values are not equal just because they look alike.

```python
print(1 == 1.0)
print("1" == 1)
print("5" == "5")
```

```text
True
False
True
```

Ordering comparisons between incompatible types are errors:

```python error
print("a" < 1)
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print("a" < 1)
TypeError: '<' not supported between instances of 'str' and 'int'
```

This is a very common bug when a number was read with `input()` and never converted. If `age` is still the string `"17"`, then `age >= 18` raises this exact error.

## Comparing strings

Strings compare character by character using their Unicode code points. That means comparisons are **case sensitive**, and uppercase letters sort before lowercase ones.

```python
print("apple" < "banana")
print("Zebra" < "apple")
print("Apple" == "apple")
print("Apple".lower() == "apple".lower())
```

```text
True
True
False
True
```

When you want a case-insensitive comparison, convert both sides to the same case first, as in the last line.

## Membership with `in`

The `in` operator asks whether something is contained in something else. For strings it checks for a substring.

```python
print("py" in "python")
print("java" in "python")
print("x" not in "abc")
```

```text
True
False
True
```

It also works on lists, sets, dictionaries and more, as you will see in later modules.

## Floats and equality

Because floats are approximate, comparing them with `==` is unreliable.

```python
import math

print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
```

```text
False
True
```

Use `math.isclose` for computed floats, or round both sides to the precision you care about.

## `==` versus `is`

`==` asks whether two values are **equal**. `is` asks whether two names point at the **same object**. You met `is` in lesson 1.1.2.

```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b)
print(a is b)
print(a is c)
```

```text
True
False
True
```

`a` and `b` hold equal contents but are separate lists. `a` and `c` are the same list. Use `==` for comparing values. Reserve `is` for checking against `None`, which you will meet in lesson 1.2.5.

## Booleans are numbers too

`True` behaves as `1` and `False` as `0` in arithmetic. That makes counting matches easy.

```python
print(True + True)
print(sum([5 > 3, 2 > 1, 4 > 9]))
```

```text
2
2
```

## Common mistakes

- **`=` instead of `==`.** Assignment versus comparison.
- **Comparing a string to a number.** `"18" >= 18` is a `TypeError`. Convert with `int()` first.
- **Comparing floats with `==`.** Use `math.isclose`.
- **Forgetting that comparisons are case sensitive.** Normalise with `.lower()`.
- **Boundaries.** `x > 30` and `x >= 30` differ at exactly 30. Decide which side each boundary belongs to.

## Recap

- Comparisons produce `True` or `False`, which are values of type `bool`.
- `==` compares and `=` assigns. Chain comparisons for ranges: `30 <= x < 75`.
- Strings compare case sensitively. Different types are not equal, and ordering them is an error.
- Use `math.isclose` for floats and `in` for membership.
- `==` compares values. `is` compares identity.
