# Advanced Iteration & itertools

Python's `itertools` module is a toolbox of **lazy building blocks** for iteration. Each tool takes iterables and returns an iterator, so you can snap them together into pipelines that use almost no memory and are written in fast C. Most programmers use the same dozen tools again and again. Learn those and a whole class of loops becomes one line.

## Infinite iterators: count, cycle, repeat

```python
from itertools import count, cycle, repeat, islice

print(list(islice(count(10), 5)))          # 10, 11, 12, ...
print(list(islice(count(0, 5), 4)))        # step of 5
print(list(islice(cycle("ABC"), 7)))       # A B C A B C A
print(list(repeat("x", 3)))                # x x x
```

```text
[10, 11, 12, 13, 14]
[0, 5, 10, 15]
['A', 'B', 'C', 'A', 'B', 'C', 'A']
['x', 'x', 'x']
```

All three never stop on their own, so pair them with `islice`, `zip`, or a `break`. A handy use: `zip(count(1), names)` numbers things, which is what `enumerate` does for you. `cycle` is perfect for round-robin assignment:

```python
from itertools import cycle

workers = cycle(["w1", "w2", "w3"])
tasks = ["a", "b", "c", "d", "e"]
print([(task, next(workers)) for task in tasks])
```

```text
[('a', 'w1'), ('b', 'w2'), ('c', 'w3'), ('d', 'w1'), ('e', 'w2')]
```

## islice: slicing for iterators

Iterators cannot be sliced with `[a:b]`. `islice` does the equivalent without building a list:

```python
from itertools import islice

squares = (n * n for n in range(1000))
print(list(islice(squares, 5)))
print(list(islice(squares, 2, 4)))      # continues from where the last one stopped

first_line, second_line = islice(["one", "two", "three"], 2)
print(first_line, second_line)
```

```text
[0, 1, 4, 9, 16]
[49, 64]
one two
```

The second `islice` skipped two more items from the **already advanced** iterator. Remember that iterators are one-shot.

## chain: glue iterables end to end

```python
from itertools import chain

print(list(chain([1, 2], (3, 4), "56")))

groups = [[1, 2], [3], [4, 5, 6]]
print(list(chain.from_iterable(groups)))
print(sum(1 for _ in chain.from_iterable(groups)))
```

```text
[1, 2, 3, 4, '5', '6']
[1, 2, 3, 4, 5, 6]
6
```

`chain.from_iterable` is the memory-friendly way to flatten one level, lazily.

## accumulate: running totals

`accumulate` yields every partial result as it folds a function across the data, which `reduce` throws away:

```python
from itertools import accumulate
import operator

print(list(accumulate([1, 2, 3, 4, 5])))
print(list(accumulate([1, 2, 3, 4, 5], operator.mul)))
print(list(accumulate([3, 1, 4, 1, 5, 9, 2], max)))

balance = list(accumulate([100, -30, -20, 75, -60], initial=0))
print(balance)
```

```text
[1, 3, 6, 10, 15]
[1, 2, 6, 24, 120]
[3, 3, 4, 4, 5, 9, 9]
[0, 100, 70, 50, 125, 65]
```

By default it adds. Give it another function for products or a running maximum, and `initial=` sets a starting value that is included in the output. Running balances and prefix sums (lesson 2.1.5) are one call.

## groupby: consecutive runs and groups

`groupby` collects **consecutive** items that share a key. The crucial rule: **sort first** if you want all equal keys together.

```python
from itertools import groupby

data = "AAABBBCCAA"
print([(key, len(list(group))) for key, group in groupby(data)])

words = ["apple", "avocado", "banana", "blueberry", "cherry", "apricot"]
for letter, group in groupby(sorted(words), key=lambda w: w[0]):
    print(letter, list(group))
```

```text
[('A', 3), ('B', 3), ('C', 2), ('A', 2)]
a ['apple', 'apricot', 'avocado']
b ['banana', 'blueberry']
c ['cherry']
```

The first line is **run-length encoding**: `AAABBBCCAA` becomes `A3 B3 C2 A2`. Notice the final `AA` formed a separate group, because groupby only merges neighbours. In the second example, sorting first made each letter's words adjacent.

```python
from itertools import groupby
from operator import itemgetter

sales = [("east", 10), ("west", 5), ("east", 7), ("west", 3), ("north", 9)]
sales.sort(key=itemgetter(0))
totals = {region: sum(v for _, v in rows) for region, rows in groupby(sales, key=itemgetter(0))}
print(totals)
```

```text
{'east': 17, 'north': 9, 'west': 8}
```

Another trap: each `group` is itself a **lazy iterator tied to the main one**. Use it (or turn it into a list) before moving to the next group.

## Combinatorics: product, permutations, combinations

These generate arrangements without writing nested loops:

```python
from itertools import product, permutations, combinations, combinations_with_replacement

print(list(product("AB", [1, 2])))
print(len(list(product(range(3), repeat=3))))
print(list(permutations("ABC", 2)))
print(list(combinations("ABCD", 2)))
print(list(combinations_with_replacement("AB", 2)))
```

```text
[('A', 1), ('A', 2), ('B', 1), ('B', 2)]
27
[('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]
[('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'C'), ('B', 'D'), ('C', 'D')]
[('A', 'A'), ('A', 'B'), ('B', 'B')]
```

| Tool | Order matters? | Repeats allowed? | Example size for n=4, k=2 |
|---|---|---|---|
| `product` | yes | yes | 16 |
| `permutations` | yes | no | 12 |
| `combinations` | no | no | 6 |
| `combinations_with_replacement` | no | yes | 10 |

A realistic use is a parameter grid, trying every setting combination:

```python
from itertools import product

sizes = ["S", "M", "L"]
colors = ["red", "blue"]
variants = [f"{s}-{c}" for s, c in product(sizes, colors)]
print(variants)

# the nested loops it replaces
manual = []
for s in sizes:
    for c in colors:
        manual.append(f"{s}-{c}")
print(variants == manual)
```

```text
['S-red', 'S-blue', 'M-red', 'M-blue', 'L-red', 'L-blue']
True
```

Combinatorics grows fast: 10 items give 3,628,800 permutations. They are lazy, so you can stop early, but be careful before asking for `list(...)` of one.

## zip_longest, pairwise and batched

```python
from itertools import zip_longest, pairwise, batched

print(list(zip("abc", [1, 2])))
print(list(zip_longest("abc", [1, 2], fillvalue="-")))

prices = [10, 12, 9, 15]
print([b - a for a, b in pairwise(prices)])

print([list(b) for b in batched(range(7), 3)])
```

```text
[('a', 1), ('b', 2)]
[('a', 1), ('b', 2), ('c', '-')]
[2, -3, 6]
[[0, 1, 2], [3, 4, 5], [6]]
```

- `zip` stops at the shortest input, `zip_longest` pads with a fill value.
- `pairwise` gives overlapping neighbour pairs: the **changes** between consecutive values.
- `batched` chunks an iterable into groups of `n` (the last one may be shorter). It needs Python 3.12 or newer, which is what the editor runs.

## takewhile, dropwhile, compress, starmap

```python
from itertools import takewhile, dropwhile, compress, starmap
import operator

nums = [1, 3, 5, 8, 2, 4, 7]
print(list(takewhile(lambda n: n < 6, nums)))
print(list(dropwhile(lambda n: n < 6, nums)))

print(list(compress("ABCDEF", [1, 0, 1, 0, 1, 1])))
print(list(starmap(operator.mul, [(2, 5), (3, 4), (10, 10)])))
print(list(starmap(pow, [(2, 3), (3, 2)])))
```

```text
[1, 3, 5]
[8, 2, 4, 7]
['A', 'C', 'E', 'F']
[10, 12, 100]
[8, 9]
```

`takewhile` stops at the **first** failure, unlike `filter`, which tests everything. `starmap` unpacks each tuple into the function's arguments, like `map` for functions with several parameters.

## tee: split one iterator into several

A single iterator is one-shot. `tee` makes independent copies so several consumers can each read the whole stream:

```python
from itertools import tee

source = iter([1, 2, 3, 4])
a, b = tee(source)
print(sum(a), max(b))

evens_source, odds_source = tee(range(10))
print(list(filter(lambda n: n % 2 == 0, evens_source)), list(filter(lambda n: n % 2, odds_source)))
```

```text
10 4
[0, 2, 4, 6, 8] [1, 3, 5, 7, 9]
```

After calling `tee`, do not touch the original iterator. `tee` has to buffer whatever one copy has read that the other has not, so for a huge stream where the consumers run far apart, a list may be cheaper.

## Recipe: building a streaming pipeline

Put it together. "From an endless stream of numbers, take the squares of the odd ones, stop when they exceed 200, and report running totals":

```python
from itertools import count, takewhile, accumulate

odd_squares = (n * n for n in count(1, 2))
small = takewhile(lambda sq: sq < 200, odd_squares)
print(list(accumulate(small)))
```

```text
[1, 10, 35, 84, 165, 286, 455]
```

An infinite stream, three lazy stages, and a stop condition, all in four lines with no list until the very end.

## Common mistakes

- **`groupby` without sorting.** Equal keys that are not adjacent become separate groups.
- **Reading a `groupby` group late.** Consume it before advancing the outer loop.
- **Calling `list()` on an infinite iterator.** It never returns. Limit with `islice`.
- **Using the original iterator after `tee`.**
- **Expecting `takewhile` to skip failures.** It stops at the first one.
- **Huge `permutations` or `product` expanded into a list.** The count explodes.

## Practice

1. Use `groupby` to **decode** run-length data: given `[("A", 3), ("B", 2)]`, produce `"AAABB"`.
2. Use `accumulate` to compute the running maximum of `[3, 1, 4, 1, 5, 9, 2, 6]`.
3. Use `combinations` to count how many pairs of the numbers `1..6` add up to 7.
4. Use `product` to list all 2-digit binary strings, and then all 3-digit ones.

+++ Solutions
```python
def decode(pairs):
    return "".join(char * n for char, n in pairs)

print(decode([("A", 3), ("B", 2)]))   # AAABB

from itertools import accumulate, combinations, product

print(list(accumulate([3, 1, 4, 1, 5, 9, 2, 6], max)))   # [3, 3, 4, 4, 5, 9, 9, 9]
print(sum(1 for a, b in combinations(range(1, 7), 2) if a + b == 7))   # 3
print(["".join(bits) for bits in product("01", repeat=2)])   # ['00', '01', '10', '11']
print(len(["".join(bits) for bits in product("01", repeat=3)]))   # 8
```

## Recap

- `itertools` provides **lazy**, memory-friendly building blocks. Combine them into pipelines.
- **Infinite:** `count`, `cycle`, `repeat`, limited with `islice` (the iterator version of slicing).
- **Combine:** `chain`/`chain.from_iterable` glue iterables, `zip_longest` pads, `pairwise` gives neighbours, `batched` chunks.
- **Fold:** `accumulate` returns running totals, maxima or products, with `initial=` for a start value.
- **Group:** `groupby` merges **consecutive** equal keys, so **sort first**, and use each group before moving on.
- **Arrangements:** `product`, `permutations`, `combinations`, `combinations_with_replacement`. They grow explosively.
- `takewhile`, `dropwhile`, `compress` and `starmap` filter and map in lazy form, and `tee` splits one iterator into several.
