# Level-Order BFS & Tree Serialization

Depth-first search dives down one branch. **Breadth-first search** sweeps the tree **level by level**: the root, then its children, then the grandchildren. It is the tool for questions about distance and levels ("what is on each floor?"), and it is the base for **saving** a tree as text and rebuilding it later.

## Level-order with a queue

Lesson 2.2.4 introduced the queue for this. Take a node from the front, process it, and add its children to the back. Because the queue is first-in, first-out, a whole level is always finished before the next begins.

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def level_order(root):
    if root is None:
        return []
    out, queue = [], deque([root])
    while queue:
        node = queue.popleft()
        out.append(node.val)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    return out

root = TreeNode(3, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
print(level_order(root))
```

```text
[3, 9, 20, 15, 7]
```

## One list per level

To keep levels separate, process **exactly the nodes that are in the queue at the start of each round**. Its length is the size of the current level:

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def levels(root):
    if root is None:
        return []
    out, queue = [], deque([root])
    while queue:
        row = []
        for _ in range(len(queue)):      # only this level
            node = queue.popleft()
            row.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        out.append(row)
    return out

root = TreeNode(3, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
print(levels(root))
```

```text
[[3], [9, 20], [15, 7]]
```

That `for _ in range(len(queue))` line is the whole trick. From here, many problems are a few edits away:

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def right_side_view(root):
    """What you see standing on the right: the last node of each level."""
    if root is None:
        return []
    out, queue = [], deque([root])
    while queue:
        size = len(queue)
        for i in range(size):
            node = queue.popleft()
            if i == size - 1:
                out.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    return out

def level_averages(root):
    out, queue = [], deque([root] if root else [])
    while queue:
        size = len(queue)
        total = 0
        for _ in range(size):
            node = queue.popleft()
            total += node.val
            queue.extend(c for c in (node.left, node.right) if c)
        out.append(total / size)
    return out

root = TreeNode(1, TreeNode(2, None, TreeNode(5)), TreeNode(3, None, TreeNode(4)))
print(right_side_view(root))
print(level_averages(root))
```

```text
[1, 3, 4]
[1.0, 2.5, 4.5]
```

BFS costs O(n) time. Its memory is the widest level, which for a balanced tree is about n / 2, while DFS needs only the height. Pick BFS when the answer is about **levels or the shortest distance**, DFS when it is about **paths or subtrees**.

## Zigzag order

A small twist: alternate the direction of every level. Reverse each odd row, and the BFS itself does not change:

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def zigzag(root):
    out, queue, flip = [], deque([root] if root else []), False
    while queue:
        row = []
        for _ in range(len(queue)):
            node = queue.popleft()
            row.append(node.val)
            queue.extend(c for c in (node.left, node.right) if c)
        out.append(row[::-1] if flip else row)
        flip = not flip
    return out

root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3, TreeNode(6), TreeNode(7)))
print(zigzag(root))
```

```text
[[1], [3, 2], [4, 5, 6, 7]]
```

## Serialization: tree to text and back

A tree lives in memory as objects and pointers. To **save** it to a file or **send** it over a network, you need a flat string, and a way to rebuild the tree from it exactly. That pair of operations is **serialization** and **deserialization**.

The trick is to record the **missing children** too, using a marker such as `#`. Otherwise two different trees could produce the same list. Here is a level-order version:

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def serialize(root):
    out, queue = [], deque([root])
    while queue:
        node = queue.popleft()
        if node is None:
            out.append("#")
            continue
        out.append(str(node.val))
        queue.append(node.left)
        queue.append(node.right)
    while out and out[-1] == "#":       # trim trailing markers
        out.pop()
    return ",".join(out)

def deserialize(text):
    if not text:
        return None
    parts = text.split(",")
    root = TreeNode(int(parts[0]))
    queue, i = deque([root]), 1
    while queue and i < len(parts):
        node = queue.popleft()
        if i < len(parts) and parts[i] != "#":
            node.left = TreeNode(int(parts[i]))
            queue.append(node.left)
        i += 1
        if i < len(parts) and parts[i] != "#":
            node.right = TreeNode(int(parts[i]))
            queue.append(node.right)
        i += 1
    return root

root = TreeNode(1, TreeNode(2), TreeNode(3, TreeNode(4), TreeNode(5)))
text = serialize(root)
print(text)
back = deserialize(text)
print(serialize(back) == text, back.right.left.val)
print(repr(serialize(None)))
```

```text
1,2,3,#,#,4,5
True 4
''
```

Deserialization mirrors serialization: read parts in the same order, and every real node takes the next two entries as its children. A round trip (`serialize(deserialize(s)) == s`) is the test of correctness.

## Serialization with preorder

Depth-first works as well, and the recursion is shorter. A preorder walk with markers is enough to rebuild the tree, because the markers say exactly where each branch ends:

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def to_text(node):
    if node is None:
        return "#"
    return f"{node.val},{to_text(node.left)},{to_text(node.right)}"

def from_text(text):
    tokens = iter(text.split(","))
    def build():
        t = next(tokens)
        if t == "#":
            return None
        return TreeNode(int(t), build(), build())
    return build()

root = TreeNode(1, TreeNode(2), TreeNode(3, TreeNode(4), TreeNode(5)))
s = to_text(root)
print(s)
print(to_text(from_text(s)) == s)
```

```text
1,2,#,#,3,4,#,#,5,#,#
True
```

(`TreeNode(int(t), build(), build())` is safe because Python evaluates arguments left to right, so the left subtree is built first.) Real systems use formats like **JSON**, which is a serialization of nested dictionaries and lists, the same idea.

## Rebuilding from two traversals

Preorder alone cannot rebuild a tree without markers, but **preorder plus inorder** can, if values are unique. Preorder's first item is the root, and its position in the inorder list splits the left and right subtrees:

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def build(preorder, inorder):
    if not preorder:
        return None
    index = {v: i for i, v in enumerate(inorder)}
    pos = iter(preorder)
    def make(lo, hi):                     # inorder slice [lo, hi)
        if lo >= hi:
            return None
        val = next(pos)
        mid = index[val]
        node = TreeNode(val)
        node.left = make(lo, mid)
        node.right = make(mid + 1, hi)
        return node
    return make(0, len(inorder))

def post(n):
    return [] if n is None else post(n.left) + post(n.right) + [n.val]

tree = build([3, 9, 20, 15, 7], [9, 3, 15, 20, 7])
print(post(tree))
```

```text
[9, 15, 7, 20, 3]
```

The dictionary makes finding the split O(1), so the whole rebuild is O(n).

## Common mistakes

- **Forgetting to freeze the level size.** `len(queue)` must be read **before** the loop adds children.
- **Using a list as the queue.** `pop(0)` is O(n). Use `deque`.
- **Skipping the `#` markers.** Without them the text does not identify one tree.
- **Reading tokens out of order** in deserialization. The reader must consume exactly what the writer produced.
- **Mixing up BFS and DFS memory.** BFS holds a whole level, DFS only one path.

## Practice

1. Write `min_depth(root)`: the number of levels down to the **first leaf**, using BFS so you can stop early.
2. Write `bottom_up_levels(root)`: levels listed from the deepest to the root.
3. Write `width(root)`: the size of the widest level.
4. Why can the preorder list `[1, 2, 3]` (without markers) correspond to several different trees?

+++ Solutions
```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def min_depth(root):
    if root is None:
        return 0
    queue, depth = deque([root]), 0
    while queue:
        depth += 1
        for _ in range(len(queue)):
            n = queue.popleft()
            if n.left is None and n.right is None:
                return depth
            queue.extend(c for c in (n.left, n.right) if c)

def levels(root):
    out, queue = [], deque([root] if root else [])
    while queue:
        row = []
        for _ in range(len(queue)):
            n = queue.popleft()
            row.append(n.val)
            queue.extend(c for c in (n.left, n.right) if c)
        out.append(row)
    return out

def bottom_up_levels(root):
    return levels(root)[::-1]

def width(root):
    return max((len(r) for r in levels(root)), default=0)

t = TreeNode(3, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
print(min_depth(t), bottom_up_levels(t), width(t))   # 2 [[15, 7], [9, 20], [3]] 2
```

With `[1, 2, 3]` and no markers, 2 could be 1's left child or right child, and 3 could hang off 1 or off 2. The shape is lost, so you need the missing-child markers.

## Recap

- **Level-order BFS** uses a queue: pop a node, push its children. Memory is the widest level.
- Reading `len(queue)` at the start of each round gives **one list per level**, the base for right-side view, averages, zigzag and minimum depth.
- **Serialization** turns a tree into text. Record missing children with a marker like `#` so the shape survives.
- Deserialization consumes the tokens in the same order they were written (level-order with a queue, or preorder with recursion).
- Preorder plus inorder (with unique values) also rebuilds a tree, using a dictionary to find each split in O(1).
