# Binary Trees & DFS Traversals

Lists are lines. Real data often branches: a folder holds folders, a company has teams inside departments, a family has children who have children. The structure for that is a **tree**, and the simplest useful one is the **binary tree**, where each node has at most two children. Trees are also the first structure in this course where **recursion feels natural** instead of clever.

## Nodes, roots and leaves

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

#        1
#       / \
#      2   3
#     / \
#    4   5
root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(root.val, root.left.val, root.left.right.val, root.right.left)
```

```text
1 2 5 None
```

The vocabulary: the top node is the **root**. A node's `left` and `right` are its **children**, and it is their **parent**. A node with no children is a **leaf**. The **depth** of a node counts the edges down from the root, and the **height** of a tree is the longest root-to-leaf path.

A tree is a **recursive** structure: each child is itself the root of a smaller tree, and `None` is the empty tree. That is the key to everything below.

## The recursive template

Any question about a tree can be answered by combining the answers for the left and right subtrees:

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

def count(node):
    if node is None:
        return 0
    return 1 + count(node.left) + count(node.right)

def total(node):
    if node is None:
        return 0
    return node.val + total(node.left) + total(node.right)

root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(height(root), count(root), total(root))
```

```text
3 5 15
```

The shape never changes: **base case** for `None`, then **trust** the recursive calls on the two children and combine. Each node is visited once, so these run in **O(n)**. The recursion goes as deep as the tree is tall, which is the **O(h)** memory cost of the call stack.

## Depth-first traversals

A **traversal** visits every node. Depth-first search goes all the way down one branch before backing up. The only choice is *when* you handle the current node relative to its two subtrees:

| Order | Visit order | Typical use |
|---|---|---|
| **preorder** | node, left, right | copy a tree, print a folder outline |
| **inorder** | left, node, right | read a search tree in sorted order |
| **postorder** | left, right, node | delete a tree, compute sizes bottom-up |

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def preorder(n):
    return [] if n is None else [n.val] + preorder(n.left) + preorder(n.right)

def inorder(n):
    return [] if n is None else inorder(n.left) + [n.val] + inorder(n.right)

def postorder(n):
    return [] if n is None else postorder(n.left) + postorder(n.right) + [n.val]

root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(preorder(root))
print(inorder(root))
print(postorder(root))
```

```text
[1, 2, 4, 5, 3]
[4, 2, 5, 1, 3]
[4, 5, 2, 3, 1]
```

The names say where the **node** goes: *pre*, *in*, or *post* its children. The code differs only in the position of `[n.val]`.

## The same thing with an explicit stack

Recursion uses the call stack, which has a limit (lesson 2.2.3). A degenerate tree that is just a long chain, with 100,000 nodes, overflows it. The loop version keeps its own stack:

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def preorder_iter(root):
    out, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        out.append(node.val)
        if node.right:                 # push right first so left is popped first
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return out

def inorder_iter(root):
    out, stack, cur = [], [], root
    while cur or stack:
        while cur:                     # go as far left as possible
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        out.append(cur.val)
        cur = cur.right
    return out

root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(preorder_iter(root))
print(inorder_iter(root))

chain = None
for i in range(100_000):
    chain = TreeNode(i, chain)
print(len(preorder_iter(chain)))
```

```text
[1, 2, 4, 5, 3]
[4, 2, 5, 1, 3]
100000
```

## Questions that return a value up the tree

Often each subtree **reports** something and the parent combines the reports. Is a tree symmetric? What is the longest path between any two nodes?

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def is_mirror(a, b):
    if a is None and b is None:
        return True
    if a is None or b is None or a.val != b.val:
        return False
    return is_mirror(a.left, b.right) and is_mirror(a.right, b.left)

def diameter(root):
    best = 0
    def depth(node):
        nonlocal best
        if node is None:
            return 0
        l, r = depth(node.left), depth(node.right)
        best = max(best, l + r)        # a path that bends at this node
        return 1 + max(l, r)           # but only one side continues upward
    depth(root)
    return best

sym = TreeNode(1, TreeNode(2, TreeNode(3), TreeNode(4)), TreeNode(2, TreeNode(4), TreeNode(3)))
print(is_mirror(sym.left, sym.right))
tree = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(diameter(tree))
```

```text
True
3
```

`diameter` shows the most useful pattern: a helper returns one thing (the height) while updating another (the best answer so far) through `nonlocal`.

## Root-to-leaf paths

Passing information **down** works too. This collects every path from the root to a leaf, carrying the path so far as an argument:

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def paths(node, prefix=()):
    if node is None:
        return []
    prefix = prefix + (node.val,)
    if node.left is None and node.right is None:
        return [prefix]
    return paths(node.left, prefix) + paths(node.right, prefix)

root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(paths(root))
print([sum(p) for p in paths(root)])
```

```text
[(1, 2, 4), (1, 2, 5), (1, 3)]
[7, 8, 4]
```

## Common mistakes

- **Forgetting the `None` base case.** You will hit `AttributeError: 'NoneType' object has no attribute 'left'`.
- **Mixing up height and depth.** Depth counts from the root down, height from a node down to the deepest leaf.
- **Using `if node.left:` to test for a child when values can be 0.** Compare with `is None` when a node itself might be falsy. (A `TreeNode` object is always truthy, but be consistent.)
- **Returning from the wrong place.** In `diameter` the value passed up differs from the answer recorded.
- **Deep recursion on skewed trees.** Use the explicit stack version.

## Practice

1. Write `max_value(root)` returning the largest value in a tree.
2. Write `leaves(root)` returning all leaf values from left to right.
3. Write `is_same(a, b)` checking whether two trees have identical shape and values.
4. Write `invert(root)` that swaps left and right at every node.

+++ Solutions
```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def max_value(n):
    if n is None:
        return float("-inf")
    return max(n.val, max_value(n.left), max_value(n.right))

def leaves(n):
    if n is None:
        return []
    if n.left is None and n.right is None:
        return [n.val]
    return leaves(n.left) + leaves(n.right)

def is_same(a, b):
    if a is None or b is None:
        return a is b
    return a.val == b.val and is_same(a.left, b.left) and is_same(a.right, b.right)

def invert(n):
    if n is not None:
        n.left, n.right = invert(n.right), invert(n.left)
    return n

t = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3))
print(max_value(t), leaves(t), is_same(t, t))   # 5 [4, 5, 3] True
print(leaves(invert(t)))                         # [3, 5, 4]
```

## Recap

- A binary tree node has a value and up to two children. The top is the **root**, childless nodes are **leaves**.
- Trees are recursive: the base case is `None`, and the answer combines the answers for the left and right subtrees.
- **Preorder, inorder, postorder** differ only in when the node is handled relative to its children. All are O(n) time and O(h) stack.
- An explicit stack gives the same traversals without recursion limits.
- Helpers can **return up** (height) while recording a separate answer (diameter), or pass information **down** (path so far).
