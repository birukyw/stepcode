# Bitwise Algebra & Bitmasks

Computers store everything as bits, and Python lets you reach right down to them. Bit operations are tiny, fast, and surprisingly powerful: they pack a set of yes/no flags into one number, test whether a number is a power of two in one step, and find the odd one out of a million values without extra memory. This lesson makes them feel natural.

## Numbers as bits

Every integer is a row of bits. Python can show them:

```python
for n in [5, 12, 255]:
    print(n, bin(n), format(n, "08b"))
print(int("1011", 2), 0b1011, 0xFF)
```

```text
5 0b101 00000101
12 0b1100 00001100
255 0b11111111 11111111
11 11 255
```

`bin(5)` is `0b101`: one 4, no 2s, one 1. `format(n, "08b")` pads to 8 digits, and `int(text, 2)` goes back.

## The six operators

| Operator | Name | Rule | Example |
|---|---|---|---|
| `a & b` | AND | 1 only if both are 1 | `12 & 10 = 8` |
| `a \| b` | OR | 1 if either is 1 | `12 \| 10 = 14` |
| `a ^ b` | XOR | 1 if they differ | `12 ^ 10 = 6` |
| `~a` | NOT | flips every bit | `~5 = -6` |
| `a << k` | left shift | multiply by 2ᵏ | `3 << 2 = 12` |
| `a >> k` | right shift | divide by 2ᵏ, rounding down | `12 >> 2 = 3` |

```python
a, b = 0b1100, 0b1010
print(format(a & b, "04b"), format(a | b, "04b"), format(a ^ b, "04b"))
print(3 << 2, 12 >> 2, 1 << 10)
print(~5, -7 >> 1)
```

```text
1000 1110 0110
12 3 1024
-6 -4
```

`~5` is `-6` because Python integers use two's complement: `~n == -n - 1`. Shifting left by `k` is the fastest way to multiply by a power of two, and `1 << k` builds a number with just bit `k` set.

## Reading and changing single bits

With `1 << i` as a **mask** that selects bit `i` (counting from 0 on the right):

```python
def get_bit(n, i):   return (n >> i) & 1
def set_bit(n, i):   return n | (1 << i)
def clear_bit(n, i): return n & ~(1 << i)
def flip_bit(n, i):  return n ^ (1 << i)

n = 0b1010
print(get_bit(n, 1), get_bit(n, 2))
print(format(set_bit(n, 0), "04b"), format(clear_bit(n, 3), "04b"), format(flip_bit(n, 1), "04b"))
```

```text
1 0
1011 0010 1000
```

The pattern: **OR sets, AND with a NOT clears, XOR flips, shift and AND reads.**

## Classic one-liners

Two identities cover a surprising number of problems.

`n & (n - 1)` **clears the lowest set bit**, because subtracting 1 flips the lowest 1 and every zero below it.

```python
def is_power_of_two(n):
    return n > 0 and n & (n - 1) == 0

def count_bits(n):
    count = 0
    while n:
        n &= n - 1              # remove one set bit per loop
        count += 1
    return count

print([is_power_of_two(x) for x in (1, 2, 6, 64, 100)])
print(count_bits(0b10110111), bin(0b10110111).count("1"))
```

```text
[True, True, False, True, False]
6 6
```

`n & -n` **isolates the lowest set bit**:

```python
for n in (12, 40, 7):
    print(n, format(n, "b"), n & -n)
```

```text
12 1100 4
40 101000 8
7 111 1
```

## XOR: the cancelling operator

XOR has three properties that make it special: `a ^ a = 0`, `a ^ 0 = a`, and the order does not matter. So XOR-ing a list in which every value appears twice except one makes all the pairs cancel and leaves the odd one out, in O(n) time and O(1) memory:

```python
from functools import reduce
from operator import xor

def single_number(nums):
    return reduce(xor, nums, 0)

print(single_number([4, 1, 2, 1, 2]))
print(single_number([7]))

a, b = 5, 9
a ^= b; b ^= a; a ^= b          # swap without a temporary
print(a, b)
```

```text
4
7
9 5
```

(In everyday Python, `a, b = b, a` is the clearer swap. The XOR version is a curiosity, but the cancelling idea is real.)

## Bitmasks: a set in one number

If your universe has at most a few dozen items, a number can act as a **set**: bit `i` is 1 when item `i` is present. Union is OR, intersection is AND, membership is a shifted AND.

```python
PERMS = {"read": 1 << 0, "write": 1 << 1, "delete": 1 << 2}

user = PERMS["read"] | PERMS["write"]
print(bool(user & PERMS["write"]), bool(user & PERMS["delete"]))
user |= PERMS["delete"]
user &= ~PERMS["write"]
print([name for name, bit in PERMS.items() if user & bit])
```

```text
True False
['read', 'delete']
```

File permissions, feature flags and graphics options all work this way: one integer carries all the yes/no answers.

## Enumerating every subset

A set of `n` items has 2ⁿ subsets, and the numbers `0` to `2ⁿ - 1` represent exactly one subset each. So a plain loop visits them all:

```python
items = ["a", "b", "c"]
for mask in range(1 << len(items)):
    subset = [items[i] for i in range(len(items)) if mask & (1 << i)]
    print(format(mask, "03b"), subset)
```

```text
000 []
001 ['a']
010 ['b']
011 ['a', 'b']
100 ['c']
101 ['a', 'c']
110 ['b', 'c']
111 ['a', 'b', 'c']
```

This powers brute-force searches over small sets, such as "choose the best combination of up to 20 items". Always check that `2ⁿ` is affordable: 20 items means about a million masks, 30 means a billion.

A common companion is `mask & (mask - 1)`-style tricks to iterate submasks, but the loop above is the one to know first.

## A real use: a compact flag board

Eight yes/no cells in a single byte, printed as a row:

```python
def show(board):
    return "".join("#" if board >> i & 1 else "." for i in range(8))

board = 0
for cell in (0, 2, 3, 7):
    board |= 1 << cell
print(show(board), board)
```

```text
#.##...# 141
```

## Common mistakes

- **Precedence.** `&`, `|` and `^` bind **more loosely than `==`**: `n & 1 == 0` means `n & (1 == 0)`. Always write `(n & 1) == 0`.
- **Using `and`/`or` for bits.** `and`/`or` work on truth values, `&`/`|` work on bits.
- **Shifting by a negative amount** raises `ValueError`.
- **Forgetting Python integers are unbounded.** `~x` is negative and there is no fixed 32-bit wraparound. Mask with `& 0xFFFFFFFF` when you need a fixed width.
- **Counting bits from the wrong side.** Bit 0 is the rightmost (least significant).

## Practice

1. Write `is_even(n)` using only a bit operation.
2. Write `hamming_distance(a, b)`: how many bits differ between two numbers?
3. Find the two numbers that appear once in `[1, 2, 3, 2, 1, 4]`. (Hint: XOR everything, then split by the lowest set bit of the result.)
4. Use a bitmask to test whether a string contains only distinct lowercase letters, with no set or dict.

+++ Solutions
```python
def is_even(n):
    return (n & 1) == 0

def hamming_distance(a, b):
    return bin(a ^ b).count("1")

print(is_even(10), is_even(7), hamming_distance(0b1011, 0b0110))   # True False 3
```

```python
def two_singles(nums):
    total = 0
    for n in nums:
        total ^= n                 # x ^ y, the two unique values
    low = total & -total           # a bit where x and y differ
    x = 0
    for n in nums:
        if n & low:
            x ^= n
    return sorted((x, total ^ x))

print(two_singles([1, 2, 3, 2, 1, 4]))   # [3, 4]
```

```python
def all_distinct(text):
    seen = 0
    for ch in text:
        bit = 1 << (ord(ch) - ord("a"))
        if seen & bit:
            return False
        seen |= bit
    return True

print(all_distinct("python"), all_distinct("hello"))   # True False
```

## Recap

- Integers are rows of bits. `bin`, `format(n, "b")` and `int(text, 2)` convert.
- `&` AND, `|` OR, `^` XOR, `~` NOT, `<<` and `>>` shift. `1 << i` is a mask for bit `i`.
- **OR sets, AND-NOT clears, XOR flips, shift-and-AND reads** a bit.
- `n & (n - 1)` clears the lowest set bit (power of two test, bit counting), and `n & -n` isolates it.
- XOR cancels equal pairs, which finds the odd one out in O(1) memory.
- A number can be a **set** (bitmask), and `range(1 << n)` enumerates every subset.
- Put parentheses around bit operations next to `==`.
