# 2D Grids & Nested Loops

A loop inside another loop is how you walk over a grid: rows and columns, a game board, an image, a table. The outer loop picks the row. The inner loop walks across it. This lesson covers how nested loops run, how to print patterns with them, and how to reason about how much work they do.

## A loop inside a loop

```python
for row in range(3):
    for col in range(4):
        print("#", end=" ")
    print()
```

```text
# # # # 
# # # # 
# # # # 
```

Read it from the outside in. For each of the 3 values of `row`, the inner loop runs completely, printing 4 symbols. The empty `print()` after the inner loop ends the line, so the next row starts underneath.

The key fact: **the inner loop restarts from the beginning on every iteration of the outer loop**. If the outer loop runs 3 times and the inner loop runs 4 times, the innermost body runs `3 * 4 = 12` times.

## Coordinates

The two loop variables are the coordinates of each cell: (row, column). Printing them shows the visiting order:

```python
for row in range(2):
    for col in range(3):
        print(f"({row},{col})", end=" ")
    print()
```

```text
(0,0) (0,1) (0,2) 
(1,0) (1,1) (1,2) 
```

The grid is visited row by row, left to right. The inner variable changes fastest, like the seconds hand compared to the minutes hand of a clock.

## Multiplication table

Because every cell is a function of its row and column, a table is easy to build:

```python
for row in range(1, 5):
    for col in range(1, 6):
        print(f"{row * col:3}", end="")
    print()
```

```text
  1  2  3  4  5
  2  4  6  8 10
  3  6  9 12 15
  4  8 12 16 20
```

The `:3` in the f-string pads each number to a width of 3, which lines up the columns.

## Shapes that depend on the row

The inner loop does not have to run the same number of times on every row. Make its limit depend on the outer variable and you get triangles.

```python
for row in range(1, 6):
    for col in range(row):
        print("*", end="")
    print()
```

```text
*
**
***
****
*****
```

Row 1 prints one star, row 2 prints two, and so on. The inner `range(row)` grows with the outer loop.

Flip the relationship for a downward triangle:

```python
n = 5
for row in range(n, 0, -1):
    print("*" * row)
```

```text
*****
****
***
**
*
```

The second version uses string repetition instead of an inner loop. Both are valid. Use the inner loop when each cell needs its own logic, and repetition when a whole row is uniform.

## A centred pyramid

Combine leading spaces with stars. Each row has `n - row` spaces followed by `2 * row - 1` stars.

```python
n = 4
for row in range(1, n + 1):
    print(" " * (n - row) + "*" * (2 * row - 1))
```

```text
   *
  ***
 *****
*******
```

Finding the formulas is the real work. Draw the first few rows, count spaces and stars, and look for the relationship with the row number.

## Choosing what to print per cell

Because the inner loop sees both coordinates, each cell can decide what to show. A checkerboard alternates based on whether `row + col` is even:

```python
for row in range(4):
    for col in range(8):
        print("#" if (row + col) % 2 == 0 else ".", end="")
    print()
```

```text
#.#.#.#.
.#.#.#.#
#.#.#.#.
.#.#.#.#
```

The diagonal of a grid, where the row equals the column, is just a condition:

```python
n = 5
for row in range(n):
    for col in range(n):
        print("X" if row == col else ".", end=" ")
    print()
```

```text
X . . . . 
. X . . . 
. . X . . 
. . . X . 
. . . . X 
```

An upper-triangular pattern, where only cells on or above the diagonal are filled, uses `col >= row`:

```python
n = 4
for row in range(n):
    for col in range(n):
        print("#" if col >= row else " ", end="")
    print()
```

```text
####
 ###
  ##
   #
```

## Counting work

How long does a nested loop take? The body runs `rows * cols` times. For a square grid of size `n`, that is `n * n`, written `n²`.

```python
count = 0
for i in range(100):
    for j in range(100):
        count += 1
print(count)
```

```text
10000
```

Doubling the grid size quadruples the work. This is the first appearance of an idea that Track 2 builds on: loops nested to depth two grow **quadratically**. A grid of 1,000 by 1,000 cells needs a million iterations, which is fine. Three nested loops of 1,000 would need a billion, which is not.

Triangular loops, where the inner range depends on the outer variable, do about half as much work as the full square: roughly `n² / 2`.

## Accumulators in nested loops

The accumulator pattern still applies. Initialise **outside both loops**, update inside the innermost one:

```python
total = 0
for row in range(1, 4):
    for col in range(1, 4):
        total += row * col
print(total)
```

```text
36
```

Initialising `total` inside the outer loop would reset it for every row, and initialising it inside the inner loop would reset it for every cell.

## Common mistakes

- **Forgetting the empty `print()`** after the inner loop. Every row runs together on one line.
- **Using the same variable name in both loops.** `for i ... for i ...` makes the inner `i` shadow the outer one. Use `row`/`col` or `i`/`j`.
- **Initialising an accumulator at the wrong level.** Decide whether it should reset per row or never.
- **Off-by-one in a triangle.** Print the first three rows by hand and compare.
- **Confusing the order.** The first loop is the **slowest** moving coordinate.

## Recap

- A nested loop runs its inner loop completely for every iteration of the outer loop.
- The two loop variables are the (row, column) coordinates of each cell.
- Make the inner range depend on the outer variable to draw triangles and pyramids.
- A grid of `rows * cols` cells costs `rows * cols` iterations, so doubling both quadruples the work.
- Keep accumulators outside the loops they must survive, and print a newline after each row.
