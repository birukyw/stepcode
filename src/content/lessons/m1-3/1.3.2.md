# Counting with Sequences & range

A `while` loop is flexible, but when you already know what to loop over, a `for` loop is shorter and safer. It handles the initialise, test and update steps for you, which removes the bugs that came from forgetting them. This lesson covers `for`, the `range()` function that generates counting sequences, and the half-open convention behind them.

## The for loop

A `for` loop takes each item of a sequence in turn and runs the block once per item.

```python
for letter in "code":
    print(letter)
```

```text
c
o
d
e
```

The variable after `for` (here `letter`) is the **loop variable**. Python assigns it a new value on every iteration. A string is a sequence of characters, so looping over it visits one character at a time. Lists, covered in module 1.4, work the same way.

## Counting with range

To repeat something a given number of times, loop over `range()`.

```python
for i in range(5):
    print(i)
```

```text
0
1
2
3
4
```

`range(5)` produces the numbers `0, 1, 2, 3, 4`. It starts at zero and stops **before** 5. That is a half-open interval, `[0, 5)`, the same convention as slicing and as the `30 <= x < 75` ranges from module 1.2.

The half-open rule has a handy consequence: `range(n)` always produces exactly `n` numbers.

## Start, stop and step

`range` takes up to three arguments.

| Call | Produces |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(2, 6)` | 2, 3, 4, 5 |
| `range(0, 10, 3)` | 0, 3, 6, 9 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

```python
for i in range(2, 6):
    print(i, end=" ")
print()

for i in range(0, 10, 3):
    print(i, end=" ")
print()

for i in range(5, 0, -1):
    print(i, end=" ")
print()
```

```text
2 3 4 5 
0 3 6 9 
5 4 3 2 1 
```

Passing `end=" "` to `print` keeps the output on one line, which makes the sequence easy to read. The last example counts **down** by using a negative step, and notice that it stops before 0, since the stop value is always excluded.

> **Tip:** To see exactly what a range contains, convert it to a list: `list(range(0, 10, 3))` gives `[0, 3, 6, 9]`.

```python
print(list(range(5)))
print(list(range(2, 6)))
print(len(range(10, 20)))
```

```text
[0, 1, 2, 3, 4]
[2, 3, 4, 5]
10
```

## Choosing between for and while

Use `for` when you know the sequence in advance: a number of repetitions, the characters of a string, the items of a list. Use `while` when you repeat until a condition becomes true and cannot predict how many steps that takes. If you find yourself writing `i = 0`, `while i < n` and `i += 1`, you almost certainly want `for i in range(n)`.

## Using the loop variable

Often the number itself is useful, not just the repetition. Summing the numbers from 1 to 100:

```python
total = 0
for n in range(1, 101):
    total += n
print(total)
```

```text
5050
```

`range(1, 101)` is the idiom for "1 through 100 inclusive". The stop value is always one more than the last number you want.

A multiplication table row:

```python
for i in range(1, 6):
    print(f"7 x {i} = {7 * i}")
```

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

## Position and value together

Sometimes you need both the position and the character. `enumerate()` gives you pairs:

```python
for position, letter in enumerate("abc"):
    print(position, letter)
```

```text
0 a
1 b
2 c
```

`enumerate` starts counting at 0. Pass a second argument to change that: `enumerate("abc", 1)` starts at 1.

## Ignoring the loop variable

If you only want to repeat something and have no use for the counter, the convention is to name it `_`:

```python
for _ in range(3):
    print("beep")
```

```text
beep
beep
beep
```

## What range cannot do

`range` works with whole numbers only.

```python error
for i in range(2.5):
    print(i)
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    for i in range(2.5):
TypeError: 'float' object cannot be interpreted as an integer
```

If a value arrives as a float, such as the result of `/`, convert it with `int()` or use `//`. And if you read the count from `input()`, remember it is a string: `range(int(input()))`.

## The loop variable keeps its last value

After a `for` loop ends, the loop variable still exists and holds the last value it was given:

```python
for i in range(4):
    pass
print(i)
```

```text
3
```

That surprises people who expect it to be 4. It is occasionally useful, but never rely on it when the loop might have run zero times, because then the variable was never created.

## Changing the loop variable has no effect

Assigning to the loop variable inside the body does not change how the loop proceeds. Python takes the next value from the range regardless.

```python
for i in range(3):
    i = i * 10
    print(i)
```

```text
0
10
20
```

Each iteration begins with a fresh value, so the loop still visits three values. If you want different steps, change the `range` arguments instead.

## Common mistakes

- **Off by one.** `range(1, 10)` ends at 9, not 10. To include 10, write `range(1, 11)`.
- **Counting down without a negative step.** `range(5, 0)` is empty. You need `range(5, 0, -1)`.
- **Using floats in `range`.** Convert to `int` first.
- **Forgetting that `range(n)` starts at 0.** Add 1 when you want to display "1 to n".
- **Looping with `range(len(x))` out of habit.** When you do not need the index, loop over the items directly.

## Recap

- `for item in sequence:` runs the block once per item. Strings are sequences of characters.
- `range(stop)`, `range(start, stop)` and `range(start, stop, step)` generate whole-number sequences. The stop value is excluded.
- Use a negative step to count down. `range(n)` always has exactly `n` numbers.
- `enumerate` gives position and value together. `_` marks an unused loop variable.
- Use `for` when you know the sequence in advance and `while` when you wait for a condition.
