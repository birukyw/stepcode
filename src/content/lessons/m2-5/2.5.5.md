# Weighted Shortest Paths (Dijkstra & Bellman-Ford)

BFS finds the route with the **fewest edges**. A real map needs the route with the **smallest total weight**: kilometres, minutes, toll cost. The shortest-in-edges path can be the longest in kilometres. This lesson builds the two standard algorithms for weighted graphs: **Dijkstra**, fast and elegant, and **Bellman-Ford**, slower but able to handle negative weights.

## Why BFS fails here

```python
graph = {
    "A": [("B", 1), ("C", 10)],
    "B": [("C", 1)],
    "C": [],
}
# fewest edges to C: A -> C (1 edge, cost 10)
# cheapest to C:     A -> B -> C (2 edges, cost 2)
direct = 10
via_b = 1 + 1
print(direct, via_b, via_b < direct)
```


## Dijkstra's idea

Keep the best known distance to every node. Repeatedly take the **closest node not yet finalized**, and see whether going through it improves its neighbours. The key fact: with **non-negative weights**, once the closest unfinished node is picked, no later path can reach it more cheaply, so its distance is final.

"Give me the closest unfinished node" is exactly what a **min-heap** does (lesson 2.4.4):

```python
import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if d > dist.get(node, float("inf")):
            continue                              # a stale entry: a shorter way was already found
        for nxt, w in graph[node]:
            nd = d + w
            if nd < dist.get(nxt, float("inf")):
                dist[nxt] = nd
                heapq.heappush(heap, (nd, nxt))
    return dist

graph = {
    "A": [("B", 4), ("C", 1)],
    "B": [("D", 1)],
    "C": [("B", 2), ("D", 5)],
    "D": [],
}
print(dijkstra(graph, "A"))
```

```text
{'A': 0, 'B': 3, 'C': 1, 'D': 4}
```

A to B directly costs 4, but A to C to B costs 1 + 2 = 3, and A to D is then 3 + 1 = 4. The `if d > dist...: continue` line skips heap entries that were superseded. Python's heap cannot update an item in place, so we push a new better entry and ignore the old one when it surfaces ("lazy deletion").

Each edge is relaxed at most once and each push costs log, so Dijkstra runs in **O((V + E) log V)**.

## Recovering the path

Remember which node gave each best distance:

```python
import heapq

def shortest_path(graph, start, goal):
    dist = {start: 0}
    parent = {start: None}
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if node == goal:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return d, path[::-1]
        if d > dist.get(node, float("inf")):
            continue
        for nxt, w in graph[node]:
            nd = d + w
            if nd < dist.get(nxt, float("inf")):
                dist[nxt] = nd
                parent[nxt] = node
                heapq.heappush(heap, (nd, nxt))
    return None

graph = {
    "A": [("B", 4), ("C", 1)], "B": [("D", 1)],
    "C": [("B", 2), ("D", 5)], "D": [], "Z": [],
}
print(shortest_path(graph, "A", "D"))
print(shortest_path(graph, "A", "Z"))
```

```text
(4, ['A', 'C', 'B', 'D'])
None
```

Stopping when the goal is **popped** (not merely discovered) is correct, because only then is its distance final.

## A bigger picture: a road network

```python
import heapq

roads = [
    ("Home", "Cafe", 2), ("Home", "Park", 5), ("Cafe", "Park", 2),
    ("Cafe", "Library", 7), ("Park", "Library", 3), ("Park", "Gym", 4),
    ("Library", "Gym", 1), ("Gym", "Work", 6), ("Library", "Work", 8),
]
graph = {}
for a, b, w in roads:
    graph.setdefault(a, []).append((b, w))
    graph.setdefault(b, []).append((a, w))

def dijkstra(start):
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue
        for nxt, w in graph[node]:
            if d + w < dist.get(nxt, 10**9):
                dist[nxt] = d + w
                heapq.heappush(heap, (d + w, nxt))
    return dist

dist = dijkstra("Home")
for place in sorted(dist, key=dist.get):
    print(place, dist[place])
```

```text
Home 0
Cafe 2
Park 4
Library 7
Gym 8
Work 14
```

Notice Dijkstra computed the distance to **every** node in one run. That is "single-source shortest paths".

## Negative weights break Dijkstra

Some graphs have negative edges: a refund, a discount, an energy gain. Dijkstra's key fact collapses: a path that looks longer might become cheaper later through a negative edge, after the node was already finalized.

## Bellman-Ford: relax everything, repeatedly

Bellman-Ford does something simpler and slower: **relax every edge, V - 1 times**. Relaxing means "can I improve the distance to `b` by going through `a`?". Any shortest path has at most V - 1 edges, so after V - 1 rounds every distance is correct.

```python
def bellman_ford(nodes, edges, start):
    dist = {n: float("inf") for n in nodes}
    dist[start] = 0
    for _ in range(len(nodes) - 1):
        changed = False
        for a, b, w in edges:
            if dist[a] + w < dist[b]:
                dist[b] = dist[a] + w
                changed = True
        if not changed:
            break
    return dist

nodes = ["A", "B", "C", "D"]
edges = [("A", "B", 4), ("A", "C", 5), ("B", "C", -3), ("C", "D", 2)]
print(bellman_ford(nodes, edges, "A"))
```

```text
{'A': 0, 'B': 4, 'C': 1, 'D': 3}
```

A to C directly costs 5, but A to B to C costs 4 - 3 = 1. Cost: **O(V × E)**, much slower than Dijkstra, so use it only when negative weights exist.

### Negative cycles

If a cycle's total weight is negative, you could loop forever making the path shorter, so shortest distances are undefined. Run **one more round**: if anything still improves, a negative cycle is reachable.

```python
def has_negative_cycle(nodes, edges, start):
    dist = {n: float("inf") for n in nodes}
    dist[start] = 0
    for _ in range(len(nodes) - 1):
        for a, b, w in edges:
            if dist[a] + w < dist[b]:
                dist[b] = dist[a] + w
    return any(dist[a] + w < dist[b] for a, b, w in edges)

nodes = ["A", "B", "C"]
print(has_negative_cycle(nodes, [("A", "B", 1), ("B", "C", -2), ("C", "A", -1)], "A"))
print(has_negative_cycle(nodes, [("A", "B", 1), ("B", "C", -2), ("C", "A", 5)], "A"))
```

```text
True
False
```

Currency arbitrage is a negative-cycle search: take logs of exchange rates, and a profitable loop is a cycle whose weights sum below zero.

## Choosing the algorithm

| Situation | Algorithm | Cost |
|---|---|---|
| All edges equal | BFS | O(V + E) |
| Non-negative weights | **Dijkstra** | O((V + E) log V) |
| Negative weights allowed | **Bellman-Ford** | O(V × E) |
| A DAG, any weights | topological order + one relaxation pass | O(V + E) |
| All pairs, small V | Floyd-Warshall | O(V³) |

A\* is Dijkstra with a heuristic that nudges it toward the goal, and is what game and map software often use.

## Common mistakes

- **Dijkstra with negative weights.** It silently gives wrong answers.
- **Not skipping stale heap entries.** Still correct but slower, and wrong if you mark nodes final on discovery.
- **Stopping on discovery, not on pop.** The first time you see the goal is not always the cheapest.
- **Using BFS on weighted graphs.**
- **Comparing floats for equality** in distances. Use integers or a tolerance.

```python
def cheapest_flight(n, flights, src, dst, k):
    INF = float("inf")
    cost = [INF] * n
    cost[src] = 0
    for _ in range(k + 1):
        nxt = cost[:]
        for a, b, w in flights:
            if cost[a] + w < nxt[b]:
                nxt[b] = cost[a] + w
        cost = nxt
    return cost[dst] if cost[dst] != INF else -1

print(cheapest_flight(3, [(0, 1, 100), (1, 2, 100), (0, 2, 500)], 0, 2, 1))   # 200
print(cheapest_flight(3, [(0, 1, 100), (1, 2, 100), (0, 2, 500)], 0, 2, 0))   # 500
```

```python
import heapq

def network_delay(times, n, k):
    graph = {i: [] for i in range(1, n + 1)}
    for u, v, w in times:
        graph[u].append((v, w))
    dist = {k: 0}
    heap = [(0, k)]
    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue
        for nxt, w in graph[node]:
            if d + w < dist.get(nxt, float("inf")):
                dist[nxt] = d + w
                heapq.heappush(heap, (d + w, nxt))
    return max(dist.values()) if len(dist) == n else -1

print(network_delay([(2, 1, 1), (2, 3, 1), (3, 4, 1)], 4, 2))   # 2
```

```python
import heapq

def count_shortest(graph, start):
    dist = {start: 0}
    ways = {start: 1}
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue
        for nxt, w in graph[node]:
            nd = d + w
            if nd < dist.get(nxt, float("inf")):
                dist[nxt] = nd
                ways[nxt] = ways[node]
                heapq.heappush(heap, (nd, nxt))
            elif nd == dist[nxt]:
                ways[nxt] += ways[node]
    return ways

g = {"A": [("B", 1), ("C", 1)], "B": [("D", 1)], "C": [("D", 1)], "D": []}
print(count_shortest(g, "A")["D"])   # 2
```

Scanning for the minimum each time costs O(V) per step, so O(V²) overall. A heap finds it in O(log V), giving O((V + E) log V), a big win on sparse graphs.

## Recap

- With weights, fewest edges is not cheapest. **Dijkstra** repeatedly finalizes the closest unfinished node using a **min-heap**: O((V + E) log V).
- It requires **non-negative** weights. Skip stale heap entries, and stop when the goal is **popped**.
- Track a `parent` map to rebuild the route.
- **Bellman-Ford** relaxes every edge V - 1 times (O(V × E)) and tolerates **negative weights**. One extra round that still improves reveals a negative cycle.
- Pick the tool by the graph: BFS (unweighted), Dijkstra (non-negative), Bellman-Ford (negative), a topological pass (DAG).
