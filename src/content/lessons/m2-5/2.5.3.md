# Shortest Paths on Unweighted Graphs (Multi-Source BFS)

If every edge costs the same, the shortest path is the one with the **fewest edges**. Depth-first search wanders, so it will happily find a long route. **Breadth-first search** spreads out like a ripple in a pond: first everything one step away, then two steps away, and so on. The first time it reaches a node, it has found the shortest way there. This is how "degrees of separation", maze solvers and GPS first guesses work.

## BFS gives distances

Lesson 2.4.2 used a queue to sweep a tree level by level. On a graph it is the same loop, plus a visited set so that nothing is entered twice:

```python
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D", "E"],
    "D": ["B", "C", "F"],
    "E": ["C", "F"],
    "F": ["D", "E"],
}

def distances(start):
    dist = {start: 0}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for nxt in graph[node]:
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                queue.append(nxt)
    return dist

print(distances("A"))
```

```text
{'A': 0, 'B': 1, 'C': 1, 'D': 2, 'E': 2, 'F': 3}
```

Because the queue is first-in, first-out, nodes leave it in order of distance. So the **first** time a node gets a distance, that distance is the smallest possible. The `dist` dictionary doubles as the visited set. Total cost: **O(V + E)**.

## Recovering the path

Store where each node was **discovered from**, then walk backward:

```python
from collections import deque

graph = {
    "A": ["B", "C"], "B": ["A", "D"], "C": ["A", "D", "E"],
    "D": ["B", "C", "F"], "E": ["C", "F"], "F": ["D", "E"],
}

def shortest_path(start, goal):
    parent = {start: None}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == goal:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for nxt in graph[node]:
            if nxt not in parent:
                parent[nxt] = node
                queue.append(nxt)
    return None

path = shortest_path("A", "F")
print(len(path) - 1, path[0], path[-1])
print(shortest_path("A", "A"))
```

```text
3 A F
['A']
```

BFS can stop early the moment it dequeues the goal.

## Grids: the classic maze

On a grid each cell is a node with up to four neighbours. Walls are simply missing edges:

```python
from collections import deque

maze = [
    "S.#.....",
    ".##.###.",
    "....#...",
    ".####.#.",
    "......#E",
]

def solve(maze):
    rows, cols = len(maze), len(maze[0])
    for r in range(rows):
        for c in range(cols):
            if maze[r][c] == "S":
                start = (r, c)
            if maze[r][c] == "E":
                end = (r, c)
    dist = {start: 0}
    queue = deque([start])
    while queue:
        r, c = queue.popleft()
        if (r, c) == end:
            return dist[end]
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and maze[nr][nc] != "#" and (nr, nc) not in dist:
                dist[(nr, nc)] = dist[(r, c)] + 1
                queue.append((nr, nc))
    return -1

print(solve(maze))
print(solve(["S#E"]))
```

```text
15
-1
```

`-1` means the exit is unreachable.

## Multi-source BFS: start from many places at once

Sometimes the question is "how far is each cell from the **nearest** of several sources?" Distance from the nearest fire station, the nearest exit, the nearest zero. Running a BFS from every source separately would be slow. The trick: put **all** the sources in the queue at distance 0 before starting. The ripple then spreads from all of them at the same time:

```python
from collections import deque

def distance_to_nearest_zero(grid):
    rows, cols = len(grid), len(grid[0])
    dist = [[-1] * cols for _ in range(rows)]
    queue = deque()
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 0:
                dist[r][c] = 0
                queue.append((r, c))          # every source starts at distance 0
    while queue:
        r, c = queue.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                queue.append((nr, nc))
    return dist

for row in distance_to_nearest_zero([[0, 1, 1], [1, 1, 1], [1, 1, 0]]):
    print(row)
```

```text
[0, 1, 2]
[1, 2, 1]
[2, 1, 0]
```

One pass, **O(rows × cols)**, instead of one search per source. The same shape solves "rotting oranges" (how long until every fresh orange is infected), "walls and gates", and "nearest exit".

```python
from collections import deque

def minutes_to_rot(grid):
    rows, cols = len(grid), len(grid[0])
    queue, fresh = deque(), 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c, 0))
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    while queue:
        r, c, t = queue.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                grid[nr][nc] = 2
                fresh -= 1
                minutes = t + 1
                queue.append((nr, nc, t + 1))
    return minutes if fresh == 0 else -1

print(minutes_to_rot([[2, 1, 1], [1, 1, 0], [0, 1, 1]]))
print(minutes_to_rot([[2, 1, 1], [0, 1, 1], [1, 0, 1]]))
```

```text
4
-1
```

## BFS on states, not just maps

The "nodes" can be any situation, and "edges" the moves between them. Word ladder: change one letter at a time, each step a real word. The fewest steps is a BFS on words:

```python
from collections import deque

def ladder(start, goal, words):
    words = set(words)
    queue, seen = deque([(start, 1)]), {start}
    while queue:
        word, steps = queue.popleft()
        if word == goal:
            return steps
        for i in range(len(word)):
            for ch in "abcdefghijklmnopqrstuvwxyz":
                nxt = word[:i] + ch + word[i + 1:]
                if nxt in words and nxt not in seen:
                    seen.add(nxt)
                    queue.append((nxt, steps + 1))
    return 0

print(ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"]))
print(ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log"]))
```

```text
5
0
```

Whenever a puzzle asks for "the fewest moves" and every move costs the same, think BFS over the states.

## When BFS is the wrong tool

- **Weighted edges.** If edges have different costs, the fewest-edge path is not the cheapest one. That needs Dijkstra, two lessons ahead.
- **Huge branching.** BFS holds a whole frontier in memory, which can be enormous.
- **You only need any path, or to check reachability.** DFS is simpler and uses less memory.

## Common mistakes

- **Marking visited on dequeue** instead of on enqueue: the same node enters the queue many times.
- **`list.pop(0)` as the queue.** Use `deque`.
- **Forgetting multi-source setup.** Enqueue all sources first, then loop once.
- **Computing the distance after the fact.** Store it as you discover each node.
- **Using BFS for weighted graphs** and trusting the answer.

```python
from collections import deque

def degrees_of_separation(graph, a, b):
    dist = {a: 0}
    queue = deque([a])
    while queue:
        node = queue.popleft()
        if node == b:
            return dist[node]
        for nxt in graph.get(node, []):
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                queue.append(nxt)
    return -1

g = {"ada": ["linus"], "linus": ["ada", "grace"], "grace": ["linus"], "x": []}
print(degrees_of_separation(g, "ada", "grace"), degrees_of_separation(g, "ada", "x"))   # 2 -1
```

def walls_and_gates(rooms):
    from collections import deque
    INF = 2147483647
    rows, cols = len(rooms), len(rooms[0])
    queue = deque((r, c) for r in range(rows) for c in range(cols) if rooms[r][c] == 0)
    while queue:
        r, c = queue.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and rooms[nr][nc] == INF:
                rooms[nr][nc] = rooms[r][c] + 1
                queue.append((nr, nc))
    return rooms

INF = 2147483647
print(walls_and_gates([[INF, -1, 0], [INF, INF, INF], [0, -1, INF]]))
# [[2, -1, 0], [1, 2, 1], [0, -1, 2]]

```python
from collections import deque

def min_knight_moves(x, y):
    x, y = abs(x), abs(y)
    dist = {(0, 0): 0}
    queue = deque([(0, 0)])
    while queue:
        cx, cy = queue.popleft()
        if (cx, cy) == (x, y):
            return dist[(cx, cy)]
        for dx, dy in ((1, 2), (2, 1), (-1, 2), (-2, 1), (1, -2), (2, -1), (-1, -2), (-2, -1)):
            nx, ny = cx + dx, cy + dy
            if (nx, ny) not in dist and -2 <= nx <= x + 2 and -2 <= ny <= y + 2:
                dist[(nx, ny)] = dist[(cx, cy)] + 1
                queue.append((nx, ny))

print(min_knight_moves(5, 5), min_knight_moves(2, 1))   # 4 1
```

## Recap

- **BFS** with a queue visits nodes in order of distance, so the first time a node is reached is via a shortest (fewest-edge) path. Cost: O(V + E).
- Keep a `dist` or `parent` dictionary: it is the visited set, the distance table and the path trail at once.
- Grids are graphs; states of a puzzle are graphs. "Fewest moves" with equal costs means BFS.
- **Multi-source BFS** puts every source in the queue at distance 0 and runs once: nearest exit, nearest zero, rotting oranges.
- BFS is wrong when edges have different weights. That is Dijkstra's job.
