# Strings as Immutable Sequences

You have used strings since the first lesson. This lesson shows what they really are: **sequences of characters**, just like lists, except that they cannot be changed. That one fact explains how every string method works, and unlocks a set of tools for cutting text apart and putting it back together.

## What strings share with lists

A string supports everything you learned about sequences: indexing, negative indexes, slicing, `len`, `in` and looping.

```python
word = "python"

print(word[0], word[-1])
print(word[1:4])
print(word[::-1])
print(len(word))
print("th" in word)

for ch in word[:3]:
    print(ch)
```

```text
p n
yth
nohtyp
6
True
p
y
t
```

## Immutability

What strings cannot do is change in place.

```python error
word = "python"
word[0] = "P"
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    word[0] = "P"
TypeError: 'str' object does not support item assignment
```

To get a "modified" string, build a new one and attach the name to it:

```python
word = "python"
word = "P" + word[1:]
print(word)
```

```text
Python
```

This is exactly the situation from lesson 1.4.4. Because strings never change, one name can never affect another, and string methods **always return a new string** instead of editing the old one.

```python
name = "ada lovelace"
loud = name.upper()

print(name)
print(loud)
```

```text
ada lovelace
ADA LOVELACE
```

## Splitting and joining

`split()` breaks a string into a **list** of pieces, and `join()` glues a list of strings back into one.

```python
sentence = "the quick brown fox"

words = sentence.split()
print(words)

csv_line = "red,green,blue"
print(csv_line.split(","))

print("-".join(words))
print(" ".join(["one", "two", "three"]))
```

```text
['the', 'quick', 'brown', 'fox']
['red', 'green', 'blue']
the-quick-brown-fox
one two three
```

With no argument, `split()` cuts on any run of whitespace, which is what you usually want for words. `join` is called on the **separator**, and the list goes inside the brackets. That order surprises people at first: `"-".join(words)`, not `words.join("-")`.

## join beats repeated +=

You can build a string with `+=` in a loop, and for small cases that is fine. But each `+=` creates a whole new string, so the work grows quickly with large inputs. Collecting pieces in a list and joining them once is the idiomatic, and faster, approach.

```python
parts = []
for n in range(1, 6):
    parts.append(str(n * n))

print(", ".join(parts))
```

```text
1, 4, 9, 16, 25
```

## Cleaning up text

```python
raw = "   Hello, World!   \n"

print(repr(raw.strip()))
print(repr(raw.lstrip()))
print(repr("xxhixx".strip("x")))
print("a-b-c".replace("-", "+"))
print("Hello".startswith("He"), "Hello".endswith("lo"))
```

```text
'Hello, World!'
'Hello, World!   \n'
'hi'
a+b+c
True True
```

`strip` removes whitespace from both ends, or any characters you list. `lstrip` and `rstrip` handle one end each. `repr()` shows a string with its quotes and escapes, which makes invisible characters like `\n` visible while you debug.

## Searching

```python
text = "the cat sat on the mat"

print(text.find("cat"))
print(text.find("dog"))
print(text.count("the"))
print(text.index("sat"))
```

```text
4
-1
2
8
```

`find` returns the index of the first match, or **-1** if there is none. `index` does the same but raises a `ValueError` when the text is missing. Use `in` when you only need a yes or no.

Other tests return booleans:

```python
print("abc".isalpha(), "123".isdigit(), "abc123".isalnum(), "   ".isspace())
print("Hello".isupper(), "hello".islower())
```

```text
True True True True
False True
```

## Characters and numbers

Every character has a numeric code. `ord()` turns a character into its number and `chr()` turns the number back.

```python
print(ord("A"), ord("a"), ord("0"))
print(chr(72), chr(105))
print(chr(ord("a") + 1))
```

```text
65 97 48
H i
b
```

Letters have consecutive codes, so shifting a letter is just arithmetic. Combined with a loop and `%`, that is enough to write a Caesar cipher:

```python
message = "hello"
shift = 3
result = ""

for ch in message:
    position = ord(ch) - ord("a")
    new_position = (position + shift) % 26
    result += chr(new_position + ord("a"))

print(result)
```

```text
khoor
```

The `% 26` wraps `x`, `y` and `z` around to `a`, `b` and `c`, the same clock arithmetic as in module 1.1.

## Putting it together: a palindrome check

A palindrome reads the same forwards and backwards. Normalise the text first by lowercasing it and keeping only the letters.

```python
phrase = "A man, a plan, a canal: Panama"

cleaned = ""
for ch in phrase.lower():
    if ch.isalpha():
        cleaned += ch

print(cleaned)
print(cleaned == cleaned[::-1])
```

```text
amanaplanacanalpanama
True
```

## Sorting letters

`sorted()` accepts any sequence and returns a **list**. Join it back for a string. This gives a neat anagram test, since two words are anagrams when their sorted letters match.

```python
print(sorted("listen"))
print("".join(sorted("listen")))
print(sorted("listen") == sorted("silent"))
```

```text
['e', 'i', 'l', 'n', 's', 't']
eilnst
True
```

## Multi-line strings

`splitlines()` splits on line breaks, and a triple-quoted string keeps its lines.

```python
poem = """roses are red
violets are blue"""

for number, line in enumerate(poem.splitlines(), 1):
    print(number, line.title())
```

```text
1 Roses Are Red
2 Violets Are Blue
```

## Common mistakes

- **Trying to assign to a character.** Strings are immutable. Build a new string with slicing or `replace`.
- **Forgetting to keep the result.** `name.upper()` does nothing unless you assign it: `name = name.upper()`.
- **Mixing up `split` and `join` direction.** `"-".join(list)` and `text.split("-")`.
- **Using `find` result as a boolean.** It returns `-1` for "not found", which is truthy. Compare against `-1`, or use `in`.
- **Comparing case-sensitively by accident.** Normalise with `.lower()` first.

## Recap

- Strings are immutable sequences of characters. They support indexing, slicing, `len`, `in` and looping.
- You cannot change a string in place. String methods return **new** strings, so assign the result.
- `split()` makes a list of pieces and `"sep".join(list)` glues them back together.
- `strip`, `replace`, `find`, `count`, `startswith` and the `is...` tests cover most text cleaning.
- `ord()` and `chr()` convert between characters and numbers, which enables ciphers.
