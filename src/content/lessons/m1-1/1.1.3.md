# Arithmetic & Modular Clocks

Python is an excellent calculator, and arithmetic is the first place where its rules start to differ from what you might expect. This lesson covers every operator you will use, the two kinds of numbers, and the remainder operator that powers clocks, calendars and most "every n-th item" problems.

## The operators

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` | add | `7 + 2` | `9` |
| `-` | subtract | `7 - 2` | `5` |
| `*` | multiply | `7 * 2` | `14` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | floor divide | `7 // 2` | `3` |
| `%` | remainder (modulo) | `7 % 2` | `1` |
| `**` | power | `7 ** 2` | `49` |

## Two kinds of numbers

Whole numbers like `42` are **integers**, written `int`. Numbers with a decimal point like `3.14` are **floats**. The two behave differently in one important way: `/` always produces a float, even when the answer is a whole number.

```python
print(8 / 2)
print(8 // 2)
print(type(8 / 2))
print(type(8 // 2))
```

```text
4.0
4
<class 'float'>
<class 'int'>
```

If you mix an `int` and a `float`, the result is a `float`: `3 + 0.5` is `3.5`.

Python integers have no size limit. You will not overflow like you would in many other languages:

```python
print(2 ** 100)
```

```text
1267650600228229401496703205376
```

For readability you can put underscores in long numbers: `1_000_000` is the same as `1000000`.

## Division with a remainder

Sharing 197 minutes into hours is a division with leftovers. `//` tells you how many whole groups fit and `%` tells you what is left over.

```python
print(197 // 60)
print(197 % 60)
print(divmod(197, 60))
```

```text
3
17
(3, 17)
```

That is 3 full hours and 17 minutes left. `divmod(a, b)` gives both answers at once. Together, `//` and `%` split any number into "how many whole groups" and "what remains". The identity `a == (a // b) * b + a % b` always holds.

## Clocks wrap around

`%` is how clocks work. After 12 comes 1 again. The remainder after dividing by 12 does exactly that.

```python
hour = 10
print((hour + 5) % 12)
```

```text
3
```

Five hours after 10 is 3 o'clock, and the program agrees. Anything that cycles can be modelled this way: days of the week, positions in a ring buffer, alternating colours, and checking whether a number is even.

> **Tip:** `n % 2 == 0` is true when `n` is even. `n % 10` gives the last digit of `n`, and `n // 10` removes it.

```python
n = 4827
print(n % 10)
print(n // 10)
```

```text
7
482
```

## Negative numbers

`//` rounds **down**, toward negative infinity, not toward zero. That surprises people.

```python
print(7 // 2)
print(-7 // 2)
print(-7 % 3)
```

```text
3
-4
2
```

`-7 // 2` is `-4` because the exact answer `-3.5` rounds down to `-4`. The remainder takes the sign of the divisor, so the identity from earlier still holds: `-7 // 3` is `-3`, `-7 % 3` is `2`, and `-3 * 3 + 2` gives back `-7`.

The practical upshot is that `%` with a positive divisor always returns a result from `0` up to one less than the divisor, even for negative inputs. That is what makes it safe for wrapping around a clock.

## Order of operations

Python follows the usual precedence. From highest to lowest: parentheses, `**`, unary minus, `*` `/` `//` `%`, then `+` `-`. Operators on the same level run left to right, except `**`, which runs right to left.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(-2 ** 2)
```

```text
14
20
512
-4
```

When an expression is not obvious, add parentheses. They cost nothing and make the intent clear to the next reader.

## Floats are approximate

Computers store floats in binary, and many decimal fractions cannot be stored exactly.

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
```

```text
0.30000000000000004
False
```

This is not a Python bug. Every language using standard floats does the same. Two consequences follow:

- Never rely on `==` to compare floats you computed. Check whether they are close instead.
- For money, calculate in whole cents using integers, or round the final result.

`round(value, digits)` rounds to a number of decimal places. Python rounds exact halves to the nearest even number, so `round(2.5)` is `2` and `round(3.5)` is `4`.

```python
print(round(3.14159, 2))
print(round(2.5), round(3.5))
print(abs(-12))
```

```text
3.14
2 4
12
```

## The math module

Extra functions live in the `math` module. Bring it in with `import`.

```python
import math

print(math.sqrt(16))
print(math.floor(2.8), math.ceil(2.2))
print(round(math.pi, 4))
```

```text
4.0
2 3
3.1416
```

`math.floor` rounds down and `math.ceil` rounds up. Be careful to tell `int()`, which cuts off the decimals, apart from `floor`: they agree for positive numbers and differ for negative ones, since `int(-2.8)` is `-2` and `math.floor(-2.8)` is `-3`.

## Common mistakes

- **Expecting `/` to give an integer.** `10 / 2` is `5.0`. Use `//` for whole-number division.
- **Using `^` for powers.** In Python `^` is a different operation. Use `**`.
- **Comparing floats with `==`.** Use `math.isclose(a, b)` or compare rounded values.
- **Forgetting that `%` and `//` pair up.** Compute both from the same inputs.

## Practice

1. Convert `total_minutes = 500` into hours and minutes and print `8 hours 20 minutes` using the computed values.
2. A shop has `total_seconds = 98765`. Compute whole hours, remaining minutes and remaining seconds.
3. Day 0 is a Monday. Using `%`, work out which day of the week it is on day 100 (Monday is `0`, Sunday is `6`).
4. Print the last two digits of `1987654` using only `%`.

+++ Solutions
```python
total_minutes = 500
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours", minutes, "minutes")
```

```python
total_seconds = 98765
hours = total_seconds // 3600
minutes = (total_seconds % 3600) // 60
seconds = total_seconds % 60
print(hours, minutes, seconds)   # 27 26 5
```

```python
print(100 % 7)   # 2, which is Wednesday
```

```python
print(1987654 % 100)   # 54
```
+++

## Recap

- `/` always returns a float. `//` floors, and `%` returns the remainder.
- `**` is the power operator, and it runs right to left.
- `%` wraps values into a range, which is how clocks and cycles work.
- Floats are approximate. Compare with tolerance and round for display.
- `math` provides `sqrt`, `floor`, `ceil`, `pi` and more.
