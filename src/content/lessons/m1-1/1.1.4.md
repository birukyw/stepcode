# Strings & Pattern Assembly

A **string** is a piece of text. Nearly every program handles text somewhere: names, messages, file paths, log lines. This lesson covers how strings are written, how to join and repeat them, and how to build clean output with f-strings.

## Writing strings

Strings go inside quotes. Single and double quotes behave identically, as long as both ends match.

```python
greeting = "Hello"
nickname = 'Ada'
print(greeting, nickname)
```

```text
Hello Ada
```

Choosing the other kind of quote lets you put a quote mark inside the text without escaping:

```python
print("It's a good day")
print('She said "hi"')
```

```text
It's a good day
She said "hi"
```

## Escape sequences

A backslash gives the next character a special meaning.

| Sequence | Meaning |
|---|---|
| `\n` | new line |
| `\t` | tab |
| `\\` | a literal backslash |
| `\"` | a double quote inside a double-quoted string |

```python
print("line one\nline two")
print("name:\tAda")
print("C:\\Users\\ada")
```

```text
line one
line two
name:	Ada
C:\Users\ada
```

For text that spans several lines, use triple quotes. Everything between them is kept as written, including line breaks.

```python
banner = """Welcome
to the
terminal"""
print(banner)
```

```text
Welcome
to the
terminal
```

## Joining and repeating

`+` joins two strings. It does not add a space for you, so you need to add one yourself. `*` repeats a string, which is perfect for borders and separators.

```python
first = "Code"
second = "Quest"
print(first + second)
print(first + " " + second)
print("-" * 12)
print("ha" * 3)
```

```text
CodeQuest
Code Quest
------------
hahaha
```

> **Warning:** `"5" + 5` is an error because Python will not guess whether you meant text or arithmetic. Lesson 1.1.5 covers converting between types.

## How long is it

`len()` returns the number of characters, including spaces and punctuation.

```python
message = "Hello, world"
print(len(message))
```

```text
12
```

## Useful string methods

Strings come with built-in tools called **methods**, called with a dot after the string. Each method returns a **new** string, because strings never change in place.

```python
title = "  the sequential machine  "
print(title.strip())
print(title.strip().title())
print(title.upper())
print(title.replace("sequential", "parallel"))
print("banana".count("a"))
```

```text
the sequential machine
The Sequential Machine
  THE SEQUENTIAL MACHINE  
  the parallel machine  
3
```

`strip()` removes whitespace from both ends, `title()` capitalises each word, `upper()` and `lower()` change the case, `replace()` swaps text, and `count()` counts occurrences. Notice that `title` itself was never modified. Each call produced a fresh string.

## f-strings

Gluing many pieces together with `+` gets unreadable. An **f-string** puts values straight into the text. Write an `f` before the opening quote and wrap each variable or expression in `{}`.

```python
player = "Ada"
level = 4
print(f"{player} reached level {level}")
print(f"Next level needs {level * 100} points")
```

```text
Ada reached level 4
Next level needs 400 points
```

### Formatting inside the braces

After a colon you can control how the value is displayed.

```python
price = 1234567.891
print(f"{price:.2f}")
print(f"{price:,.2f}")
print(f"{0.256:.1%}")
print(f"{42:05d}")
```

```text
1234567.89
1,234,567.89
25.6%
00042
```

| Format | Meaning |
|---|---|
| `.2f` | two decimal places |
| `,` | thousands separator |
| `.1%` | multiply by 100, one decimal, add a percent sign |
| `05d` | integer padded with zeros to width 5 |

You can also set a width and alignment, which is how you build tidy columns:

```python
print(f"{'Item':<10}{'Price':>8}")
print(f"{'Coffee':<10}{3.5:>8.2f}")
print(f"{'Sandwich':<10}{7.25:>8.2f}")
```

```text
Item         Price
Coffee        3.50
Sandwich      7.25
```

`<` left-aligns, `>` right-aligns and `^` centres, within the width you give.

For quick debugging, add `=` after a name to print both the name and its value:

```python
speed = 42
print(f"{speed=}")
```

```text
speed=42
```

## Assembling patterns

Combining `*`, `+` and f-strings lets you draw shapes in the terminal without any loops yet:

```python
print(" " * 3 + "*")
print(" " * 2 + "*" * 3)
print(" " * 1 + "*" * 5)
print("*" * 7)
```

```text
   *
  ***
 *****
*******
```

Each line is a leading run of spaces joined to a run of stars. Notice how every line follows the same recipe, with only the numbers changing. That repetition is exactly what loops, coming in module 1.3, will automate.

## Common mistakes

- **Forgetting the `f`.** `"Hello {name}"` prints the braces literally. It must be `f"Hello {name}"`.
- **Mixing nested quotes in an f-string.** Use the other quote type inside the braces: `f"{d['key']}"`.
- **Expecting methods to change the string.** `name.upper()` on its own does nothing visible. Assign the result: `name = name.upper()`.
- **Joining text and numbers with `+`.** Use an f-string or convert with `str()`.

## Recap

- Strings are text in matching quotes. Triple quotes span lines.
- `+` joins, `*` repeats, `len()` counts characters.
- String methods return new strings. The original never changes.
- f-strings embed values and control formatting with `:` options.
