# The Sequential Machine

A program is a list of instructions. The computer reads them from the top, carries each one out completely, and only then moves to the next. It never skips ahead, never guesses what you meant, and never gets bored.

Everything else in this course sits on top of that one idea, so it is worth getting it exactly right.

## Your first instruction

`print()` tells Python to show something in the terminal. Whatever sits between the parentheses is what gets shown.

```python
print("Hello, world!")
```

Press **Run** in the editor, or use **Open in editor** on the snippet above. The text appears in the terminal on the right.

Text wrapped in quotes is called a **string**. The quotes are not part of the text. They tell Python where the text starts and stops.

## One instruction at a time

Each `print()` is one instruction, and Python runs them in the order they appear.

```python
print("Boot sequence started")
print("Loading modules")
print("Ready")
```

```text
Boot sequence started
Loading modules
Ready
```

Swap two of those lines and run it again. The output changes because the order changed. Nothing else is different, and that is the point: **the order of the lines is part of the program**.

> **Tip:** When a program gives a surprising answer, read it the way the computer does. Go one line at a time, from the top, and write down what has happened so far. Most bugs show up in that exercise.

## What print() can do

`print()` can take several values separated by commas. It prints them with a space between each.

```python
print("Score:", 42, "points")
```

```text
Score: 42 points
```

Two keyword options change its behaviour. `sep` controls what goes between values and `end` controls what is printed at the very end (a new line by default).

```python
print("2025", "11", "19", sep="-")
print("Loading", end="...")
print("done")
```

```text
2025-11-19
Loading...done
```

An empty `print()` just outputs a blank line, which is handy for spacing.

## Expressions

An **expression** is anything Python can work out into a single value. `2 + 3` is an expression and its value is `5`. A string such as `"ab"` is an expression too, and so is `"ab" + "cd"`.

```python
print(2 + 3)
print(10 - 4)
print("ab" + "cd")
```

```text
5
6
abcd
```

Python **evaluates** the expression first and only then hands the result to `print()`. That is why `print(2 + 3)` shows `5` and not `2 + 3`.

Expressions follow the maths rules you already know. Multiplication and division happen before addition and subtraction, and parentheses override everything.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

```text
14
20
```

## Statements and expressions

An expression produces a value. A **statement** is a complete instruction that does something. `print("hi")` is a statement. Most programs are just statements, one per line, and many of them contain expressions inside.

You will use this vocabulary constantly: Python **evaluates** expressions and **executes** statements.

## Comments

A line starting with `#` is a **comment**. Python ignores it completely. Use comments to explain why the code does something, since the code itself already shows what it does.

```python
# Convert minutes to seconds
print(3 * 60)   # a comment can also trail a line
```

## Reading your first errors

Errors are not failures. They are Python telling you precisely where it got stuck, and learning to read them is a core skill.

Because Python runs top to bottom, using something before it exists is an error:

```python error
print(total)
total = 10
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(total)
NameError: name 'total' is not defined
```

Read it from the bottom up. The last line names the kind of error and what went wrong. The line above it shows the code that failed. `total` was used on line 1, but it is only created on line 2, and Python has not got there yet.

A forgotten quote or bracket gives a `SyntaxError` instead, and Python refuses to run the file at all:

```python error
print("Hello)
```

```text
  File "main.py", line 1
    print("Hello)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

## Common mistakes

- **Mismatched quotes.** `"Hello'` starts with a double quote and ends with a single one. Use the same kind on both sides.
- **Missing parentheses.** `print "hi"` is Python 2 syntax and fails in Python 3.
- **Capital letters.** `Print("hi")` fails because Python is case sensitive. `print` is all lowercase.
- **Expecting Python to read ahead.** If a line depends on something, that something must come first.

## Recap

- A program is a list of statements run top to bottom, one at a time.
- `print()` shows values, and `sep` and `end` customise its output.
- Python evaluates an expression to a single value before using it.
- Comments start with `#` and are ignored.
- Read errors from the bottom up. The last line names the problem.
